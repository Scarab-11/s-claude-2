# Jw_cad 建具平面データ（JW_OPT1B.DAT）

Jw_cad の **[作図] → [建具平面]** で使う建具データを、包絡処理が正しく効くように作り替えたものです。

## ファイル

| ファイル | 内容 |
|---|---|
| `JW_OPT1B.DAT` | **配布版（14件）**。これを Jw_cad のフォルダに入れる |
| `JW_OPT1B_16件版.DAT` | 15・16番（扉厚を描く詳細版の折戸）を含む16件版。復元用 |
| `JW_OPT1B_元データ.DAT` | 作り替える前の元データ。比較用 |
| `tools/check.py` | DAT を検査して建具一覧と属性を表示する |
| `tools/make14.py` | 16件版から15・16番を取り除いて配布版を作る |

`JW_OPT1B.DAT` を Jw_cad の実行ファイルと同じフォルダ（例 `C:\jww\`）に置きます。
既存のファイルを上書きするので、元のファイルは退避しておいてください。

編集したら Jw_cad に入れる前に必ず検査を通します。

```sh
python3 tools/check.py JW_OPT1B.DAT
```

## 元データからの変更点

| 内容 | 対象 |
|---|---|
| 建具端部の線を**選択色・選択レイヤ**に | 全建具 |
| 建具部分を**線色番号2**に | 全建具 |
| 木柱部分を**線色番号4**に | 7〜10番 |
| 折戸の点線部を**実線**に | 13・14番 |
| 折戸に**端部線を追加**（他の建具と同じ形状） | 13・14番 |
| 折戸の**軸を壁の中心に**（Y+35） | 13・14番 |
| 折戸の羽根のレイヤ欄を **`-1` → `-11`** | 13・14番 |
| 15・16番を削除 | — |

座標・建具名・分割数・終端パラメータ・円弧指定（`e` 以降）は変更していません。

## データの書式

標準の資料が手元に無いため、元データの解析と Jw_cad 上での実挙動から確かめた内容です。
確証のあるものだけを書いています。

### ファイル全体

```
#1/100平面用          1行目 = データセットの見出し
#
16                    登録件数（実際の建具の数と一致していないと表示が崩れる）
999
#
<分割数>  <建具名>     空白2個以上で区切る
<データ行>...
999                   終端
#
<分割数>  <建具名>     以下、建具の数だけ繰り返す
...
```

**文字コードは CP932（Shift_JIS）、改行は CRLF。** UTF-8 で保存すると建具名が化けます。
ファイル末尾には EOF マーカー `0x1A` が付きます。

### データ行

```
始点番号 終点番号 X1 Y1 X2 Y2 [線色 線種 レイヤ] [e 角度 コード]
```

- **始点番号・終点番号** … 分割数 n のとき、建具幅 W を (n−1) 等分した n 個の基準位置を指す。
  分割数5なら 1・2・3・4・5 が左から順の基準位置
- **X1 Y1 / X2 Y2** … その基準位置からのオフセット（mm）
- **線色** … `0` = 書込線色（＝そのときの選択色）、`1`〜 = 線色番号
- **線種** … `0` = 書込線種、`1` = 実線、`2` = 点線
- **レイヤ** … 下表
- **e 角度 コード** … その線を始点まわりに回転させる。コード `12`・`13` は円弧も描く（ドアーの
  開き軌跡）、`16`・`18` は線のみ

### レイヤ欄

| 値 | 意味 |
|---|---|
| `11` | レイヤグループ1・レイヤ1（固定） |
| `1A` | レイヤグループ1・レイヤA（固定） |
| `B` | 書込レイヤグループのレイヤB（固定） |
| `-11` | 選択レイヤ（書込レイヤ）に描く |
| `-1` | 建具属性を付けて書込レイヤに描く |

`-1` と `-11` の違いが今回の不具合の原因でした。次の節を参照。

### 見込の基準

通常の建具は **Y=0 が見込の基準面**で、見込 0〜70、建具線が Y=35、
端部線は −10〜80（壁の外へ上下10ずつはみ出す）。
はみ出した分は包絡処理で壁厚ぴったりに切り揃えられます。

元データの折戸だけは **Y=0 が折戸の軸そのもの**（±50）という別の基準で描かれていたため、
壁の中心からずれていました。全体を Y+35 して他の建具と揃えてあります。

## 包絡処理の不具合について

### 症状

折戸だけ、**建具用包絡（Shift を押しながらの終点指示＝中間線消去）**をすると端部が崩れました。
普通の建具（ドアー・引違いなど）は正常でした。

### 原因

建具用包絡は**建具属性の付いた線を処理対象**にします。
折戸の羽根はレイヤ欄が `-1`（建具属性あり）だったため包絡の対象になり、
羽根が端部線から**斜めに枝分かれ**することで余計な交点ができて、端部の処理が壊れていました。

羽根のレイヤ欄を **`-11`（建具属性なし）** にすると羽根が包絡の対象から外れ、
端部線と壁だけで包絡が成立して正常になります。

### 切り分けの記録

同じ骨格に要素を1つずつ足して、壁に配置 → 建具用包絡 で確認しました。

| 試したこと | 結果 |
|---|---|
| 端部線の線色・線種・レイヤを変える（`0 0 -11` / `0 1 -11` / `0 0 -1` / `0 1 -1`） | 変化なし。属性取得で正常な建具と同一と確認済み |
| 端部線の長さを変える（±50 / ±65 / −10〜80） | 変化なし |
| 終端コードを変える（999 / 995 / 991） | 変化なし |
| 行の並び順を変える | 変化なし |
| 分割数を変える（2 / 3 / 5 / 9）※端部線＋建具線のみの骨格 | **すべて正常**。骨格自体は問題なし |
| 骨格＋中央の縦線 | 正常。中央線はシロ |
| 骨格＋羽根60度 | **崩れる** |
| 骨格＋羽根90度 | 正常。端部線と重なる向きなら問題ない |
| 羽根を内側へ2mm / 10mm ずらす | 崩れる |
| 羽根の起点を端部線の外（Y=81）へ | 崩れる |
| 羽根を80度に | 崩れる |
| 羽根の建具部分を手作業で曲線属性にする | **正常**（曲線属性は包絡の対象外になるため） |
| **羽根のレイヤ欄を `-1` → `-11` に** | **正常** ← 採用 |
| 羽根のレイヤ欄を `0` / `1` / 属性欄なしに | 線色やレイヤが崩れる。`属性欄なし` は壁と同属性になり包絡に飲み込まれて羽根が消える |

曲線属性でも直りますが、建具データの書式に曲線属性を指定する項目は見つかりませんでした。
`-11` なら DAT だけで完結し、配置のたびに手作業をする必要がありません。

## 15・16番（扉厚を描く詳細版の折戸）を外した理由

13・14番には無い `e 10 18` という行が15・16番には各4行あり、
これは**回転の中心が分割点そのもの**だと考えられます。

元データは折戸の軸が Y=0、つまり分割点と一致していたので成立していましたが、
軸を壁の中心に合わせるため全体を Y+35 したことで、回転の起点（Y=35）と
回転の中心（Y=0）が35mmずれました。15・16番は扉厚を表すために回転を数珠つなぎに
しているため、そのずれが増幅して形が破綻します。

軸を戻せば形は直りますが、今度は壁の中心からずれて包絡も効かなくなり元に戻ってしまいます。
**「軸を壁中心に合わせる」と「扉厚を表現する」が両立しない構造**です。

1/100 の図面に扉厚は不要なため、配布版からは外しました。
必要になったら `JW_OPT1B_16件版.DAT` から戻せます。

## 建具データファイルの種類

| ファイル | コマンド |
|---|---|
| `JW_OPT1*.DAT` | 建具平面 |
| `JW_OPT2*.DAT` | 建具断面 |
| `JW_OPT3*.DAT` | 建具立面 |
| `JW_OPT4*.DAT` | 線記号変形 |

末尾の英字がデータセットの識別子です。`JW_OPT1B.DAT` は建具平面の B セット。
