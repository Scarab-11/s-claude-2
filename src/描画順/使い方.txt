============================================================
 Jw_cad 外部変形 「描画順（重なり順）」  for Jw_cad Version 8.20
============================================================

 Jw_cad は「後から作図したものが上」に描かれます。
 この外部変形は、範囲選択したデータを線色番号などの「番号」の
 順に並べ替えて書き戻し、重なり順を指定どおりにします。


------------------------------------------------------------
1. しくみ
------------------------------------------------------------

 Jw_cad は jwc_temp.txt に書かれた順にデータを作図します。
 つまり、ファイルの後ろにあるものほど上（後から描画）です。

   Jw_cad ──(1) 選択したデータを jwc_temp.txt に出力
           └─(2) 描画順.bat を起動
                 └─(3) jww_draw_order.vbs が並べ替える
           ──(4) jwc_temp.txt を読み戻して作図

 (3) で先頭に「hd」を書くと、選択された元データが消えます。
 そのあとに並べ替えた順で書き戻すので、書いた順がそのまま
 新しい重なり順になります。

 ★ここが大事★
   書き戻したデータは「いま作図したもの」の扱いになるので、
   選択しなかったデータより必ず上に来ます。
   重なりを整理したいときは、重なっているものを全部まとめて
   範囲選択してください。


------------------------------------------------------------
2. インストール
------------------------------------------------------------

 このフォルダごと、Jw_cad の外部変形フォルダにコピーします。
 （例）  C:\jww\             …… jww.exe のあるフォルダ
         C:\jww\外変\描画順\ …… このフォルダ

 フォルダの中身

   描画順.bat                    対話式（毎回聞いてくる）
   描画順_最前面へ.bat           選んだものをそのまま一番上へ
   描画順_線色番号順.bat         線色1が下 … 線色9が上
   描画順_線色番号順_逆.bat      線色9が下 … 線色1が上
   描画順_線色順_12346578.bat    1,2,3,4,6,5,7,8 の順に重ねる
   描画順_レイヤ番号順.bat       レイヤ0が下 … レイヤFが上
   描画順_線色指定で最前面.bat   入力した線色だけを一番上へ
   描画順_線色指定で最背面.bat   入力した線色だけを一番下へ
   jww_draw_order.vbs            本体（バッチから呼ばれます）
   使い方.txt                    このファイル
   常駐\                         常駐ホットキー（任意）
   テスト\                       Jw_cad なしで動作確認するフォルダ

 バッチファイルと jww_draw_order.vbs は必ず同じフォルダに置いて
 ください。


------------------------------------------------------------
3. 使い方
------------------------------------------------------------

 (1) Jw_cad で [その他] － [外部変形] を選ぶ
 (2) 「描画順.bat」を選ぶ
 (3) 重なり順を変えたいデータを範囲選択する
       ・重なっているものは全部まとめて選んでください
       ・文字も対象にするときは、範囲の終点を右クリックします
         （Jw_cad の範囲選択の決まりです）
       ・[選択確定] で確定します
 (4) 並べ方を番号で入力する

       0 : 最前面へ（選択したものを、そのまま一番上に）
       1 : 番号順（番号の大きいものが上）
       2 : 番号順（番号の小さいものが上）
       3 : 並び順を自分で指定
       4 : 指定した番号だけを最前面へ
       5 : 指定した番号だけを最背面へ

 (5) 順番を決める「番号」の種類を入力する（0 のときは聞きません）

       1 : 線色番号          （線色1 〜 線色9）
       2 : 線種番号          （実線 = 1 …）
       3 : レイヤ番号        （0 〜 15。A〜F は 10〜15）
       4 : レイヤグループ番号（0 〜 15）

 (6) 3・4・5 のときは、番号をカンマ区切りで入力する

       3 のとき） 3,1,2  … 3 が一番下、2 が一番上。
                           書かなかった番号は一番下にまとめます。
       4 のとき） 2,5    … 線色2 と 線色5 を一番上に持ち上げます。
       5 のとき） 3      … 線色3 を一番下に沈めます。

 同じ番号どうしの重なり順は、もとのままです。


------------------------------------------------------------
4. 使いどころ
------------------------------------------------------------

 ・塗り（ソリッド）に隠れた線を前に出したい
     線を範囲選択して「描画順_最前面へ.bat」

 ・「線色8 は下地なので、いつも一番下にしたい」
     全体を範囲選択して「描画順_線色指定で最背面.bat」で 8 を入力

 ・線色で重ね順のルールを決めてしまいたい
     「描画順_線色番号順.bat」を使うと、線色1 が一番下、
     線色9 が一番上に統一されます。
     順番を自分で決めたいときは、対話式で 3 を選び、
     たとえば「8,1,2,3,4,5,6,7,9」のように入力します。

 ・線色 1,2,3,4,6,5,7,8 の順で重ねたい
     「描画順_線色順_12346578.bat」を使います。
     問い合わせなしで、下から
       線色1 → 2 → 3 → 4 → 6 → 5 → 7 → 8
     の順に並べ替えます。

     ※ Jw_cad 本体には「線色の順に描画する」という設定は
        ありません（jw_win.jwf にもその項目はありません）。
        描画順は作図順で決まるので、このように並べ替えて
        描き直すのが唯一の方法です。


------------------------------------------------------------
5. 毎回同じ操作をするなら（常駐）
------------------------------------------------------------

 ● Jw_cad の起動時に自動で効かせることはできません

   理由は 3 つあります。

     (1) Jw_cad には起動時にマクロを実行する仕組みがありません。
     (2) 外部変形は範囲選択が必須で、範囲が決まらないと
         jwc_temp.txt が作られず、処理そのものが始まりません。
     (3) いちばん大事な点。描画順は「データの並び順」そのもの
         であって、表示の設定ではありません。起動時に 1 回
         並べ替えても、そのあと描いた線はまた一番上に乗ります。
         「一度設定すればずっと効く」という性質のものでは
         ありません。

   つまり、作図が一区切りついたところで実行する使い方になります。

 ● できるのは「キー 1 つで実行する」ところまで

   常駐フォルダの AutoHotkey スクリプトを使うと、Jw_cad を
   操作中にキー一発で外部変形を呼び出せます。

     常駐\描画順ホットキー.ahk

       Ctrl + Alt + ↑    選んだものを最前面へ
       Ctrl + Alt + ↓    指定した線色を最背面へ
       Ctrl + Alt + L    線色順 1,2,3,4,6,5,7,8（範囲は手で選ぶ）
       Ctrl + Alt + A    同上を図面全体に適用（全自動）
       Ctrl + Alt + O    描画順（対話式）

   Ctrl + Alt + A は、メニュー操作からコントロールバーの
   [全選択] － [選択確定] まで自動で押します。押すのはキー 1 回、
   図面全体が指定の線色順に並び替わります。

   ★ Ctrl + Alt + A を使う前に

     [全選択] が拾うのは「編集可能なレイヤー」のデータだけです。
     次のものを置いたレイヤーは [表示のみ] にしておいてください。
       － ブロック図形（範囲に入れると消えます）
       － 複数の線色が混ざっている曲線属性の図形
     全選択の対象から外れて、安全に実行できます。

     最初は必ず、コピーした図面で試してください。
     結果がおかしければ [戻る] で元に戻せます。

 AutoHotkey v2 が必要です（https://www.autohotkey.com/）。
 スクリプトの先頭にある BAT_DIR を、このフォルダの実際の場所に
 書き換えてから、ダブルクリックで常駐させてください。
 Windows のスタートアップに入れておくと毎回立ち上がります。

 コントロールバーのボタンが押せないときは、スクリプト先頭の
 REAL_CLICK を true にすると、実際にマウスを動かして押します。

 AutoHotkey を入れたくない場合は、[その他] － [外部変形] から
 選ぶだけでも使えます。Jw_cad は前回選んだ外部変形フォルダを
 覚えているので、2 回目からはすぐ選べます。


------------------------------------------------------------
6. 注意事項
------------------------------------------------------------

 ・並べ替えの対象は「範囲選択したデータ」だけです。
   選択しなかったデータは、すべて下になります。

 ・外部変形の仕組み上、選択したデータはいったん消えて描き直され
   ます。データの種類ごとの結果は次のとおりです（Jw_cad 8.20 で実測）。

     ★ ブロック図形 … 消えます。分解ではありません。
        Jw_cad はブロック図形を範囲選択には含めますが、その中身を
        外部変形に渡しません。渡されなかったデータは描き直せない
        ため、消えたままになります。外部変形の側で防ぐ方法は
        ありません。必ず範囲から外してください。

       曲線属性でまとめた図形（ハッチ・連続線・多角形・曲線・
       建具・線記号変形）
         1 色だけのもの      … 保たれます
         複数の線色が混ざるもの
           … 線色ごとに分かれ、色の数だけの曲線属性になります

       寸法図形 … 寸法線と寸法値が同じ線色なら保たれます。
                  違う線色を使っている場合は壊れると考えられます
                  （未確認）。

     線・円・円弧・楕円・点・文字・ソリッドは、読んだ行をそのまま
     書き戻すため、座標も内容も変わりません。

 ・調べたいことがあるときは、バッチファイルの cscript の行に
   /dump を足して実行してください。Jw_cad から受け取った内容と
   書き戻した内容が、次の名前で .vbs と同じフォルダに残ります。
     jwc_temp_元.txt    jwc_temp_結果.txt

 ・結果がおかしいときは Jw_cad の [戻る] で元に戻せます。

 ・種類の分からないデータ行があったときは、その行を「直後の
   データにくっついている修飾行」として一緒に動かします。
   対話式のときは、その旨をダイアログに表示します。

 ・動作には cscript.exe（Windows Script Host）が必要です。

 ・前回指定した内容は jww_draw_order.ini に記憶されます。
   このファイルは実行時に自動で作られます。


------------------------------------------------------------
7. 動作確認（Jw_cad を使わずに試す）
------------------------------------------------------------

 テスト\テスト実行_線色順.bat
     サンプルの座標ファイルを線色番号順に並べ替えて、結果を
     メモ帳で表示します。上から下へ
       線色1 → 線色2 → 線色3 → 線色4 → 線色5 → 線色8
     の順に並んでいれば正常です。

 テスト\テスト実行_対話.bat
     同じサンプルを対話式で処理します。いろいろな並べ方を
     図面を触らずに試せます。
