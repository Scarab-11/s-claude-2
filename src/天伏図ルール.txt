============================================================
 天井伏図生成 ルールファイル
============================================================

 このファイルを書き換えると、外部変形の動きが変わります。
 物件ごとに書き換えて使ってください。

 ・行のあたまが # の行は説明文です（無視されます）
 ・項目名は半角の大文字で書きます
 ・保存するときは必ず「ANSI（Shift_JIS）」で保存してください

------------------------------------------------------------
1. レイヤの取捨  KEEP / DROP
------------------------------------------------------------

 平面図のうち、天井伏図に要らないもの（建具・家具・設備など）を
 レイヤ単位で落とします。書き方は次のとおりです。

   DROP  0:3      レイヤグループ0 のレイヤ3 を落とす
   DROP  *:5      すべてのグループのレイヤ5 を落とす
   DROP  5        グループを省略した形（*:5 と同じ）
   KEEP  0:0      レイヤグループ0 のレイヤ0 を残す

 ・レイヤ番号は Jw_cad と同じ 0〜f（16進）で書きます
 ・KEEP を 1 行でも書くと「書いたレイヤだけ残す」動きになります
 ・KEEP を 1 行も書かなければ「DROP したもの以外は全部残す」

 ● 天井伏図に残すレイヤ

 天井伏図には柱や建具を出さず、壁線と基準線だけを残す設定に
 してあります。そのため、残すレイヤを下に並べてあります。

 下の番号は「1階平面図」のレイヤに合わせてあります。
 別の物件では番号が違うので、レイヤ調査.bat で調べ直して
 ここを書き換えてください。

KEEP 0:f      壁の中心線（一点鎖線）
KEEP 0:1      基準線（通り芯・符号）
KEEP 0:2      部屋名
KEEP 0:d      図面名

 ここに書かなかったレイヤ（柱・建具・家具・設備・寸法など）は
 すべて落ちます。寸法も出したいなら、その行を足してください。

# KEEP 0:8    寸法

 記号と仕上表を書き込むレイヤ（下の 6. の SYMBOL_LAYER と
 LEGEND_LAYER）は、KEEP に書く必要はありません。

 ● レイヤ番号の調べ方

 一度実行すると jww_ceiling_plan.log ができ、その最後に
 「レイヤ別の内訳」が出ます。どの番号に線が何本、文字が何個
 入っていたかが分かるので、それを見て上の KEEP を直してください。

 ● レイヤを分けていない場合

 KEEP の行を全部消してください。KEEP が 1 行も無ければ
 「DROP したもの以外は全部残す」動きに変わります。
 そのうえで、余分なものが乗っているレイヤを DROP で落とします。

# DROP 0:5
# DROP *:f


------------------------------------------------------------
1-2. レイヤの線色を変える  COLOR
------------------------------------------------------------

 残したレイヤの線色を、写すときに書き換えます。

   COLOR  レイヤ  線番号

 平面図にすでに壁線（W120の二重線など）が描いてあるなら、
 下の 6. の WALL_FROM は off にして、そのレイヤを KEEP で残し、
 ここで線番号 5 に変えるのが早道です。

# COLOR 0:3 5      レイヤ0:3 の線色を 5 にする


------------------------------------------------------------
2. 室名 → 天井仕上記号
------------------------------------------------------------

 既定では「全自動」です。室名を登録しておく必要はありません。
 平面図の部屋名レイヤにある文字を全部ひろって、次の順で記号を
 決めます。

   1. 図面の中に仕上表（内部仕上概要表）があれば、そこから
      室名ごとの天井仕上を読む。同じ仕上の室は同じ記号にまとめ、
      C-1、C-2 … と番号を振る。仕上表もその結果から作る。
   2. 仕上表が読めなければ、室名ごとに番号を振る。
      仕上の欄は空で作図されるので、Jw_cad で書き込んでください。
   3. 下の ROOM に登録があれば、それを最優先で使う。

 室が増えても、室名が変わっても、そのまま実行できます。
 どの室にどの記号が付いたかは jww_ceiling_plan.log に出ます。

 ● 図面の仕上表を読ませるには

 範囲選択に「内部仕上概要表」も含めてください。表の外にあると
 読めません。表の作りは問いません。室名の右側にある文字を
 天井仕上とみなします（天井高のような数字だけの欄は飛ばします）。

 読めたかどうかはログに出ます。
     図面の仕上表をレイヤ 0:9 から読みました（11室）。

 天井の欄が室名のすぐ右に無い表（間に別の欄がある）だと、
 そちらを拾ってしまいます。そのときは下の 6. の
 SET FINISH_TABLE を off にして、ROOM で指定してください。

 ● 記号を固定したいとき  ROOM

   ROOM  室名  記号

 ログの末尾に、そのまま貼り付けられる行が出ます。

     ROOM 事務室   C-1
     ROOM 倉庫     C-3

 これを下に貼れば、その室の記号は毎回同じになります。
 一部の室だけ書いても、残りは自動で決まります。

 ・室名は図面に書いてあるとおりに書きます
 ・全角/半角、空白の有無は自動で吸収します
   （「事　務　室」と書かれていても「事務室」で拾えます）
 ・「事務室(14.46㎡)」のように後ろに何か付いていても拾えます
 ・図面で「倉庫①」と見えていても、①が別の要素なら室名の文字は
   「倉庫」だけです。枝番を付けずに ROOM 倉庫 と書いてください

 ● 室名でない文字  NOROOM

 部屋名レイヤにあっても室名でないもの（UP、DN、PS など）は
 ここに書いておくと、記号が置かれません。

NOROOM ^(UP|DN|PS|ﾊﾟｲﾌﾟｽﾍﾟｰｽ)$

 ● 天井仕上の文字を平面図側にすでに描いてある場合

 「天井仕上の文字」レイヤに C-1 などを描き込んであるなら、
 そのレイヤを KEEP して、下の 6. の SET ROOM_LAYER を off に
 してください。記号が二重に書かれるのを防げます。

 ● この物件で使っていた対応（必要なら # を外してください）

 全自動にまかせる場合は、このままで結構です。

# ROOM 事務室    C-1
# ROOM 相談室    C-1
# ROOM 玄関      C-1
# ROOM WC        C-2
# ROOM ホール    C-2
# ROOM 洋室-1    C-2
# ROOM 収納      C-2
# ROOM 階段      C-2
# ROOM 倉庫      C-3
# ROOM 軒天      C-3


------------------------------------------------------------
3. 要らない文字を消す  DROPTEXT
------------------------------------------------------------

 消したい文字を書きます（正規表現）。
 面積表記だけの文字（例「(7.85㎡)」）を消しています。

DROPTEXT ^\s*[\(（][\d.,]+\s*㎡


------------------------------------------------------------
4. 文字を書き換える  RETEXT
------------------------------------------------------------

   RETEXT  検索する文字  =>  置き換える文字

 ・置き換える文字を書かなければ、その部分が消えます
 ・検索する文字は正規表現です

 図面名を書き換えます。
RETEXT 平面図 => 天井伏図

 室名にくっついた面積表記を落とします。
 「事務室(14.46㎡(玄関含む))」→「事務室」
RETEXT \s*[\(（][\d.,]+\s*㎡.*$ =>


------------------------------------------------------------
5. 仕上表（凡例）  LEGEND
------------------------------------------------------------

   LEGEND  記号  仕上の内容

 書いた順に表になります。

 既定では、仕上表は自動で作られます（上の 2. のとおり）。
 ここに書くと、その記号の説明だけを固定できます。
 自動で作った行と混ざる場合は、ここに書いた分が先に並びます。

# LEGEND C-1 木軸下地　化粧石膏ﾎﾞｰﾄﾞt=9.5
# LEGEND C-2 木軸下地　石膏ﾎﾞｰﾄﾞt=9.5の上ﾋﾞﾆﾙｸﾛｽ貼り
# LEGEND C-3 木軸下地　ｹｲ酸ｶﾙｼｳﾑ板 t=6.0　目透かし貼りEP-G
# LEGEND C-4 見切：ｶﾞﾙﾊﾞﾘｳﾑ鋼板　t=0.8
# LEGEND C-5 ﾊﾞﾙｺﾆｰ屋根：ｱﾙﾐ既製品(ﾎﾟﾘｶｰﾎﾞﾈｲﾄ仕様)


------------------------------------------------------------
6. こまかい設定  SET
------------------------------------------------------------

 長さの単位は「図寸mm」（＝印刷したときの紙の上のmm）です。
 縮尺1/100 の図面なら、図寸1mm は実寸100mm にあたります。
 図面の縮尺は Jw_cad から渡されるので、換算は自動で行われます。
 縮尺を変えても、記号や仕上表の紙の上での大きさは変わりません。

 ● 壁線をつくる

 壁の中心線（一点鎖線）の両側に振り分けて、壁線を描きます。
 交差部や T 字部は自動でつながり、線が突き抜けません。
 中心線そのものも残るので、天井伏図の中に一点鎖線が通ります。

 壁の中心線があるレイヤ　off＝壁線を作らない
 上の KEEP に書いた「壁の中心線」と同じ番号にします。
SET WALL_FROM 0:f

 壁の厚さ（実寸mm）　ここだけは図寸ではなく実際の寸法です
SET WALL_WIDTH 120

 壁線を書くレイヤ　same＝中心線と同じ／例 0:5
SET WALL_LAYER same

 壁線の線色（線番号）
SET WALL_COLOR 5

 記号の文字種（1〜10）
SET SYMBOL_CN 3

 室名の基準線から記号の基準線までの距離（図寸mm）
SET SYMBOL_DY 4.0

 記号を書くレイヤ　same＝室名と同じ／例 0:3

 ★ここは「天井仕上の文字」レイヤの番号に必ず直してください★

 空にしてある「天井仕上の文字」レイヤへ記号を書き込む設定に
 してあります。下の 0:3 は仮の番号です。ご自分の図面の
 「天井仕上の文字」レイヤの番号（レイヤグループ:レイヤ）に
 書き換えてから使ってください。
 番号が違っていても実行はできますが、記号が別のレイヤに
 書かれます。ログの「置いた記号」の数は合っているのに図面上で
 見あたらない、というときはここを疑ってください。
SET SYMBOL_LAYER 0:3

 記号の線色　same＝室名と同じ／例 2
SET SYMBOL_COLOR same

 記号を四角の枠で囲む　on／off
SET SYMBOL_BOX on

 枠と文字とのすき間（図寸mm）
 大きくすると枠がひとまわり大きくなります。
SET SYMBOL_BOX_PAD 0.5

 枠の線色（線番号）　same＝記号と同じ
SET SYMBOL_BOX_COLOR 6

 室名の照合　prefix＝後ろに何か付いていても拾う／exact＝完全一致だけ
SET ROOM_MATCH prefix

 部屋名が入っているレイヤ　off＝ROOM に書いた室名だけを拾う
 ここを指定すると、このレイヤの文字は全部「室名」として扱われ、
 ROOM に無いものにも仮の記号が置かれます。室が増えたときに
 取りこぼさないので、指定しておくことをおすすめします。
SET ROOM_LAYER 0:2

 ROOM に無い室名の扱い
 on ＝記号を自動で割り当てる（既定）／off ＝下の ROOM_DEFAULT を置く
SET ROOM_AUTO on

 自動で割り当てる記号の頭
SET SYMBOL_PREFIX C-

 図面の中の仕上表（内部仕上概要表）を読むか
 auto＝探す（既定）／off＝読まない／例 0:9＝そのレイヤの表を読む
SET FINISH_TABLE auto

 ROOM_AUTO を off にしたとき、ROOM に無い室名に置く記号　no＝置かない
SET ROOM_DEFAULT C-?

 仕上表の書き出し　all＝全部／used＝実際に使った記号だけ／no＝書かない
SET LEGEND_MODE all

 仕上表の位置　auto＝図の右上／例 30000,12000
 ここだけは図面の座標（実寸mm）で書きます。Jw_cad の画面左下に
 出ている座標の読みを、そのまま書けば合います。
SET LEGEND_POS auto

 仕上表の記号欄の幅・仕上欄の幅・行の高さ（図寸mm）と文字種
SET LEGEND_W1 12
SET LEGEND_W2 70
SET LEGEND_RH 6
SET LEGEND_CN 3

 仕上表を書くレイヤ

 ★ここも実際のレイヤ番号に直してください★

 記号（図面の中の C-1 など）と仕上表は別のレイヤに分けています。
 上の SYMBOL_LAYER が記号、こちらが仕上表です。下の 0:4 は仮の
 番号なので、仕上表を置きたいレイヤの番号に書き換えてください。
 same にすると、仕上表は記号と同じレイヤに入ります。
SET LEGEND_LAYER 0:4

 仕上表の外枠の線色（線番号）
SET LEGEND_BORDER_COLOR 5

 仕上表の中の罫線の線色（線番号）
SET LEGEND_LINE_COLOR 2

 仕上表の文字の線色　same＝罫線と同じ／例 2
SET LEGEND_COLOR same

 仕上表の見出し（記号欄の右どなり）
SET LEGEND_TITLE 仕　上

 文字データの解釈　auto／rel（長さ成分）／abs（終点座標）
 記号の位置が思わぬ方向にずれるときだけ rel か abs に固定します。
SET CHFORMAT auto

 縮尺の分母　auto＝図面の縮尺を使う（ふつうはこのまま）
 記号や仕上表が一か所に固まって重なる、または逆に巨大になる
 ときだけ、100 や 50 のように数字で固定してください。
SET SCALE auto
