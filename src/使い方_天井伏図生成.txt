============================================================
 Jw_cad 外部変形 「天井伏図生成」   for Jw_cad Version 8.20
============================================================

 範囲選択した平面図から、天井伏図のたたき台を作る外部変形です。
 室名の文字を見つけて天井仕上記号を書き、仕上表を付けます。


------------------------------------------------------------
0. これは何をするものか（先に読んでください）
------------------------------------------------------------

 平面図から天井伏図を「全自動で」作るものではありません。

 Jw_cad から外部変形に渡ってくるのは、線・円・文字といった
 図形の並びだけで、「これは壁」「ここは相談室」という情報は
 ありません。手がかりになるのは

   ・レイヤ分け
   ・室名として書かれている文字

 の 2 つだけです。この 2 つを使って、下ごしらえの部分だけを
 引き受けます。

   できること
     ・要らないレイヤの要素を落とす（建具・家具・設備など）
     ・室名の下に天井仕上記号（C-1 など）を書く
     ・面積表記を消す、図面名を「平面図」→「天井伏図」に直す
     ・仕上表を作図する
     ・以上を、指示した位置に作図する（元の平面図は残る）

   できないこと（手で描いてください）
     ・建具の開口を壁でふさぐ
     ・軒天のラインを外壁からオフセットして作る
     ・部屋ごとの天井面を閉じた領域として起こす
     ・目透かしの目地割り、照明・換気扇・点検口の配置
     ・勾配天井、下がり天井の表現


------------------------------------------------------------
1. インストール
------------------------------------------------------------

 (1) Python 3.8 以上を用意します
       https://www.python.org/ のインストーラで入れたものなら、
       「Add Python to PATH」のチェックを忘れていても動きます
       （py ランチャーを使うため）。

       すでに Python が入っていれば、そのままで大丈夫です。
       コマンドプロンプトで

           py -3 -V

       と打ってバージョンが出れば準備完了です。

       py も python も見つからない環境では、天井伏図生成.bat を
       メモ帳で開き

           set "PYTHON="

       の行を、たとえば

           set "PYTHON=C:\Python311\python.exe"

       のように書き換えてください。

 (2) このフォルダの中身を、Jw_cad の外部変形フォルダにコピーします
       （例）  C:\jww\外変\

     フォルダの中身

       天井伏図生成.bat        これを外部変形から選びます
       レイヤ調査.bat          レイヤ番号を調べるだけのもの
       jww_ceiling_plan.py     本体（バッチから呼ばれます）
       天伏図ルール.txt        どの室にどの記号を書くかの設定
       使い方_天井伏図生成.txt このファイル
       テスト\                 Jw_cad なしで動作確認するフォルダ

     3 つとも同じフォルダに置いてください。


------------------------------------------------------------
2. 使い方
------------------------------------------------------------

 (1) Jw_cad で [その他] － [外部変形] を選ぶ
 (2) 「天井伏図生成.bat」を選ぶ
 (3) 平面図を範囲選択する
       ・「文字を含む」にチェックを入れてください
         （室名の文字を拾えないと記号が書かれません）
       ・[選択確定] で確定します
 (4) 「天井伏図を作図する位置」を指示する
       ・指示した点が、できあがる天井伏図の左下になります
       ・平面図の右どなりや下に取るとよいです
 (5) その位置に天井伏図が作図されます

 元の平面図は消えません。作図された側だけを直していけます。
 結果がおかしいときは Jw_cad の [戻る]（元に戻す）で戻せます。


------------------------------------------------------------
3. 設定（天伏図ルール.txt）
------------------------------------------------------------

 どの室にどの記号を書くか、どのレイヤを落とすかは
 「天伏図ルール.txt」で指定します。メモ帳で開けます。

 ・保存するときは必ず「ANSI（Shift_JIS）」を選んでください
   （UTF-8 で保存した場合も、BOM 付きなら読めます）
 ・行のあたまを 1 文字下げると、その行は説明文になります
 ・くわしい書き方はファイルの中に書いてあります

 最初にやること － レイヤ番号を合わせる

 このファイルには仮のレイヤ番号が入っています。★印の付いた
 3 か所を、ご自分の図面の番号に直してください。

   KEEP の行           天井伏図に残すレイヤ（壁線・基準線・部屋名）
   SET SYMBOL_LAYER    記号（C-1 など）と、その枠を書き込むレイヤ
   SET LEGEND_LAYER    仕上表を書き込むレイヤ

 番号が分からないときは、先に「レイヤ調査.bat」を実行してください。
 [その他]－[外部変形] から選び、平面図を範囲選択するだけです。
 図面には何も書かず、こういう表をメモ帳に出します。

   レイヤ別の内訳
     0:0   線    8   文字    0   残す   線の長さ 2730～8190
     0:1   線    2   文字    0   残す   線の長さ 7280～8190
     0:2   線    0   文字   14   残す   文字の例 事務室 / 相談室
     0:5   線    6   文字    0   除外   線の長さ 156～800

 線の長さと文字の例で、どのレイヤが何なのか見分けられます。

   長い線ばかり       壁の中心線か基準線
   短い線がたくさん   建具・柱・家具
   文字だけ           部屋名

 これを見て KEEP と WALL_FROM の番号を直してください。
 同じ表は、天井伏図生成.bat を実行したあとの
 jww_ceiling_plan.log の最後にも出ます。

 そのあと

   ・室名に記号が付いたか確認する。付かない室があれば、図面の
     室名の書き方に合わせて ROOM の行を足す
   ・要らないものが写っていたら、そのレイヤを KEEP から外す

 ● 天井伏図に残るもの

 KEEP に書いたレイヤだけが残ります。柱・建具・家具・設備などは
 KEEP に書かなければ落ちるので、壁線と基準線だけの図になります。
 寸法も出したいときは、寸法のレイヤを KEEP に足してください。

 ● 壁線（W120）

 壁の中心線の両側に振り分けて、壁線を描きます。交差部や T 字部は
 自動でつながるので、線が突き抜けたり角が開いたりしません。

   SET WALL_FROM 0:0     壁の中心線があるレイヤ（★要確認）
   SET WALL_WIDTH 120    壁の厚さ（実寸mm）
   SET WALL_LAYER same   壁線を書くレイヤ（same＝中心線と同じ）
   SET WALL_COLOR 5      壁線の線色

 中心線そのものも残るので、壁の中を一点鎖線が通ります。
 中心線が要らなければ、その分は Jw_cad で消してください。
 壁線が要らないときは SET WALL_FROM を off にします。

 レイヤを分けていない図面では、KEEP の行を全部消してください。
 「DROP したもの以外は全部残す」動きに変わります。

 ● 記号の枠と線色

 記号は四角の枠で囲みます。要らなければ SET SYMBOL_BOX を off に
 してください。

   SET SYMBOL_BOX_PAD 0.5    枠と文字とのすき間（図寸mm）
   SET SYMBOL_BOX_COLOR 6    枠の線色

 枠が窮屈／ゆるいと感じたら SYMBOL_BOX_PAD を 0.3〜1.0 の間で
 加減してください。

 仕上表の線色は、外枠と中の罫線で分けてあります。

   SET LEGEND_BORDER_COLOR 5   外枠
   SET LEGEND_LINE_COLOR   2   中の罫線


------------------------------------------------------------
4. 動作確認（Jw_cad なしで試す）
------------------------------------------------------------

 「テスト」フォルダの中の

   天伏図テスト実行.bat

 をダブルクリックすると、サンプルの座標ファイルを処理して結果を
 メモ帳で表示します。Jw_cad の図面を触らずに動作を確認できます。

 サンプルには「事務室」「相談室(9.94㎡)」「ﾎｰﾙ」「倉庫①」など
 書き方の違う室名が入れてあり、どれも拾えることを確かめられます。


------------------------------------------------------------
5. うまく動かないとき
------------------------------------------------------------

 実行すると jww_ceiling_plan.log ができます。
 いくつ読み込んで、いくつ落として、いくつ記号を置いたかと、
 レイヤ別の内訳が書いてあるので、まずこれを見てください。

 ● 「天井伏図にする要素がありません」と出る
    KEEP に書いたレイヤに、選んだデータが 1 つも入っていません。
    メッセージに実際のレイヤ番号が並ぶので、その番号で KEEP を
    書き直してください。

 ● 壁線が出ない／位置がおかしい
    SET WALL_FROM のレイヤ番号が、壁の中心線のレイヤと合って
    いるか確かめてください。ログの「作った壁線」が 0 なら、
    そのレイヤに線が 1 本も無かったということです。
    壁の厚さは SET WALL_WIDTH（実寸mm）で変えられます。

 ● 柱や建具が写ってしまう
    それが乗っているレイヤが KEEP に入っています。ログの
    「レイヤ別の内訳」で番号を確かめて、KEEP から外してください。

 ● 外部変形の一覧に出てこない
    バッチファイルの 2 行目「REM (井桁)jww」が消えていないか
    確認してください。この行が無いと一覧に表示されません。

 ● 範囲選択が出ず、いきなり「作図する位置を指示」になる
    バッチファイルの 3 行目が「REM (井桁)h2」になっているか
    確認してください。ここが h0 だと「範囲選択をしない」の
    意味になり、平面図を選べないまま点の指示に進みます。

 ● 「Python が見つかりません」と出る
    Python が入っていないか、py ランチャーも python も PATH に
    ありません。1.(1) を見てください。

 ● 記号がひとつも書かれない
    ・範囲選択で「文字を含む」にチェックが入っていますか
    ・図面の室名と 天伏図ルール.txt の ROOM の室名が
      合っていますか（ログの「置いた記号」が 0 なら不一致です）

 ● 記号や仕上表が一か所に固まって重なる
    図面の縮尺が正しく渡っていません。ログの「縮尺」の欄を見て、
    図面の縮尺と合っているか確かめてください。合っていなければ
    天伏図ルール.txt の SET SCALE を auto から、縮尺の分母
    （1/100 なら 100）に書き換えてください。

 ● 記号が室名から離れた所に出る
    天伏図ルール.txt の SET SYMBOL_DY の値を変えてください
    （図寸mm。大きくすると下に離れます）。
    それでも方向がおかしいときは SET CHFORMAT を auto から
    rel または abs に書き換えてみてください。
      rel … 「ch 始点X 始点Y 長さX 長さY "文字列」と解釈する
      abs … 「ch 始点X 始点Y 終点X 終点Y "文字列」と解釈する

 ● 仕上表が図に重なる / 遠い
    SET LEGEND_POS を auto から「1200,800」のように
    図寸mm の絶対座標で指定できます。

 ● 一部の要素が複写されない
    線・点・円弧・文字だけを扱います。ソリッド（塗りつぶし）や
    ブロック図形は複写されません。ログの最後に「対応していない
    要素」として個数が出ます。必要なら Jw_cad の複写で足して
    ください。

 ● 寸法図形やブロック図形
    範囲選択に含めると分解されることがあります。天井伏図では
    描き直すことが多いので、含めない方が安全です。
