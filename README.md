# Jw_cad 外部変形

Jw_cad Version 8.20 で動作確認した外部変形です。

| 外部変形 | 内容 | 動作に必要なもの |
|---|---|---|
| [文字位置揃え](#文字位置揃え) | 範囲選択した文字を横方向・縦方向それぞれ独立に指定して揃える | Windows 標準の `cscript.exe` |
| [天井伏図生成](#天井伏図生成) | 範囲選択した平面図から天井伏図のたたき台を作る | Ruby |

## ファイル構成

```
src/     編集用の原本（UTF-8 / LF）
dist/    そのまま使える実体（CP932 / CRLF）  ← Jw_cad に入れるのはこちら
tools/   src → dist の変換スクリプト
```

Jw_cad はバッチファイルの `REM` 行と `jwc_temp.txt` を Shift_JIS で読み書きするため、配布する実体は CP932 + CRLF である必要があります。リポジトリ上で読みやすいよう原本は UTF-8 で持ち、次のコマンドで変換します。

```sh
python3 tools/build.py
```

`.rb` だけは変換しません。Ruby スクリプトは先頭の `# coding: utf-8` に従って UTF-8 として読まれるため、CP932 に変換すると中の日本語リテラルが壊れます。CP932 への変換はスクリプトが `jwc_temp.txt` を書き出すときに行っています。

# 文字位置揃え

範囲選択した文字の位置を、**横方向(X)** と **縦方向(Y)** をそれぞれ独立に指定して揃える外部変形です。

Jw_cad の標準機能（範囲選択 → 文字位置・集計）では横方向の整理が中心で、縦方向を含めた一括の揃えは手数がかかります。この外部変形は横・縦を別々に指定して一度に揃えます。

## 使い方（かんたん）

1. `dist/` の中身をフォルダごと Jw_cad の外部変形フォルダ（例 `C:\jww\外変\`）にコピー
2. Jw_cad で **[その他] → [外部変形]** → `文字位置揃え.bat` を選ぶ
3. 揃えたい文字を範囲選択 → 選択確定
4. 横方向の揃え方を番号で入力 → 縦方向の揃え方を番号で入力

| 番号 | 横方向(X) | 縦方向(Y) |
|:--:|---|---|
| 0 | 揃えない | 揃えない |
| 1 | 左揃え | 下揃え |
| 2 | 中央揃え | 中央揃え |
| 3 | 右揃え | 上揃え |
| 4 | X座標を数値指定（文字の左端） | Y座標を数値指定（文字の下端） |
| 5 | 等間隔（左端どうしを等間隔に） | 等間隔（下端どうしを等間隔に） |
| 6 | 等間隔（文字のすき間を等間隔に） | 等間隔（文字のすき間を等間隔に） |

毎回同じ揃え方をする場合は、問い合わせなしで実行される固定設定のバッチ（`文字位置揃え_左揃え.bat` など8種）を使います。

詳しい説明は [`dist/使い方.txt`](dist/) を参照してください。

## 基準にする文字を指示して揃える

「一番左」ではなく「**この文字に合わせたい**」というときは `文字位置揃え_基準文字指示.bat` を使います。範囲選択のあとに基準にしたい文字をクリックすると、指示した点に一番近い文字が基準になり、左揃え・中央揃え・右揃え（下・中央・上）はその文字に合わせて動きます。基準にした文字自身は動きません。

これは `REM #1` で点を指示させ、その座標が `hp1 x y` として座標ファイルに渡ってくるのを利用しています。

## 等間隔配置

番号 5 / 6 を選ぶと、選択した文字を等間隔に割り付けます（`文字位置揃え_横に等間隔.bat` / `文字位置揃え_縦に等間隔.bat` でも実行可）。

- **5** … 文字の左端（下端）どうしが等間隔になるように動かす
- **6** … 文字と文字のすき間が等間隔になるように動かす。文字数がバラバラでも見た目の間隔がそろう

両端の文字は動かさず、間の文字を割り付けます。文字が3個以上ないと何も起こりません。

## 揃えの基準

- **左揃え / 右揃え** … 座標ファイルが持つ文字列の実長を使うため、文字数や文字種が違っても左端・右端がそろう
- **上揃え** … 文字種の文字高さ（`hch` / `cn0`）を見て上端をそろえる
- **下揃え** … 文字の基準点（左下）をそろえる
- **中央揃え** … 選択した文字全体の外形の中心に合わせる

## 仕組み

```
Jw_cad ──① 選択した文字を jwc_temp.txt に出力
        └─② 文字位置揃え.bat を起動
              └─③ jww_text_align.vbs が座標を書き換える
        ──④ jwc_temp.txt を読み戻して作図
```

バッチファイルの制御行:

| 制御行 | 意味 |
|---|---|
| `REM #jww` | jww 形式の座標ファイルを受け取る（この行が無いと外部変形の一覧に出ない） |
| `REM #h3` | 範囲内の**文字データだけ**を `jwc_temp.txt` に書き出す |
| `REM #hc …` | 範囲選択時に表示するメッセージ |
| `REM #1 …` | 点を指示させる。指示点は `hp1 x y` として渡される（基準文字指示用のバッチのみ） |
| `REM #e` | 制御文字列の終わり |

出力する `jwc_temp.txt`:

- 先頭に `hd` を書いて、選択された元の文字を削除する
- 続けて、座標を書き換えた `ch` 行と、元の属性行（`ly` / `lc` / `cn` など）をそのまま出力する
- 実行済みの印として、読み込んだ `hq` などの図面情報行は出力しない

`REM` 行の説明文に `#` を書くと Jw_cad が制御文字列として解釈してしまうため、バッチファイルのコメントには `#` を使っていません。

### 文字データの解釈について

文字データ `ch 始点X 始点Y ○ ○ "文字列` の第3・第4フィールドは、資料によって「文字列の長さ成分」と「終点座標」の2通りの説明があります。本スクリプトは読み込んだデータから**実行時に自動判定**し、どちらでも正しく動くようにしています（水平な文字なら、前者は第4=0、後者は第4=始点Y になることを利用）。

誤判定した場合は、実行後に作られる `jww_text_align.ini` の `CHFORMAT` を `auto` から `rel`（長さ成分）または `abs`（終点座標）に書き換えて固定できます。

## 動作確認

`dist/テスト/テスト実行.bat`（通常）と `dist/テスト/テスト実行_基準文字.bat`（基準文字を指示した場合）を実行すると、サンプルの座標ファイルを処理して結果をメモ帳で表示します。Jw_cad の図面を触らずに動作を確認できます。

## 注意事項

- 元の文字は `hd` で削除され、同じ内容の文字が新しい位置に書き直されます。結果がおかしいときは Jw_cad の **[戻る]** で元に戻せます。
- 寸法図形の寸法文字や、ブロック図形の中の文字は選択しないでください。
- 傾いた文字は、上下の高さを考慮せず基準点（左下）を基準に揃えます。
- 動作には `cscript.exe`（Windows Script Host）が必要です。

# 天井伏図生成

範囲選択した平面図から、**天井伏図のたたき台**を作る外部変形です。室名の文字を見つけて天井仕上記号を書き、仕上表を付けます。

## これは全自動ではありません

外部変形に渡ってくるのは線・円・文字といったプリミティブの並びだけで、「これは壁」「ここは相談室」という意味情報はありません。手がかりは**レイヤ分け**と**室名として書かれている文字**の2つだけです。この2つで届く範囲、つまり下ごしらえの部分だけを引き受けます。

| | 内容 |
|---|---|
| **やること** | 要らないレイヤの要素を落とす / 室名の下に天井仕上記号を書く / 面積表記を消す・図面名を書き換える / 仕上表を作図する / 指示した位置に作図する（元の平面図は残る） |
| **やらないこと** | 建具開口を壁でふさぐ / 軒天ラインを外壁からオフセットする / 部屋ごとの天井面を閉領域として起こす / 目地割り・照明・点検口の配置 / 勾配天井・下がり天井 |

## 使い方（かんたん）

1. **Ruby をインストールする**（[RubyInstaller](https://rubyinstaller.org/) の素の Ruby で可。PATH を通す）
2. `dist/` の中身をフォルダごと Jw_cad の外部変形フォルダにコピー
3. Jw_cad で **[その他] → [外部変形]** → `天井伏図生成.bat` を選ぶ
4. 平面図を範囲選択（**「文字を含む」にチェック**）→ 選択確定
5. 天井伏図を作図する位置（左下になる点）を指示

元の平面図は消えません。PATH を通せない場合は `天井伏図生成.bat` の `set "RUBY=ruby"` の行に `ruby.exe` のフルパスを書きます。

詳しい説明は [`dist/使い方_天井伏図生成.txt`](dist/) を参照してください。

## 設定（天伏図ルール.txt）

どの室にどの記号を書くか、どのレイヤを落とすかは `天伏図ルール.txt` で指定します。物件ごとに書き換えて使います。

```
DROP 0:3                    レイヤグループ0 のレイヤ3 を落とす
KEEP 0:0                    KEEP を1行でも書くと「書いたレイヤだけ残す」

ROOM 事務室    C-1          室名の文字を見つけて、その下に記号を書く
ROOM 倉庫①    C-3

DROPTEXT ^\s*[\(（][\d.,]+\s*㎡        面積だけの文字を消す
RETEXT   平面図 => 天井伏図             図面名を書き換える
RETEXT   \s*[\(（][\d.,]+\s*㎡.*$ =>    室名にくっついた面積を落とす

LEGEND C-1 木軸下地　化粧石膏ﾎﾞｰﾄﾞt=9.5     仕上表の行

SET SYMBOL_DY 4.0           室名から記号までの距離（図寸mm）
SET LEGEND_MODE all         all / used（使った記号だけ）/ no
SET LEGEND_POS auto         auto（図の右上）/ 例 1200,800
```

室名の照合は表記ゆれを吸収します。空白（全角含む）を無視し、Unicode 正規化（NFKC）をかけてから比べるため、「事　務　室」「ﾎｰﾙ」「洋室－１」「倉庫①」のような書き方でも拾えます。`ROOM_MATCH prefix`（既定）なら「相談室(9.94㎡)」のように後ろに何か付いていても拾います。

設定できる項目の一覧と説明は `天伏図ルール.txt` の中に書いてあります。

## 仕組み

```
Jw_cad ──① 選択した平面図を jwc_temp.txt に出力
        └─② 天井伏図生成.bat を起動
              └─③ jww_ceiling_plan.rb が
                     天伏図ルール.txt に従って作り替える
        ──④ jwc_temp.txt を読み戻して作図
```

バッチファイルの制御行:

| 制御行 | 意味 |
|---|---|
| `REM #jww` | jww 形式の座標ファイルを受け取る |
| `REM #h0` | 範囲内の**図形データ**を `jwc_temp.txt` に書き出す |
| `REM #hc …` | 範囲選択時に表示するメッセージ |
| `REM #1 …` | 作図位置を指示させる。指示点は `hp1 x y` として渡される |
| `REM #e` | 制御文字列の終わり |

出力する `jwc_temp.txt` には **`hd` を書きません**。そのため範囲選択した元の平面図は削除されず、変換結果が別位置に足される形になります。作図位置は、残す要素だけで外形を取り、その左下が指示点に来るように平行移動して決めています。

座標は図寸（紙の上の mm）で渡ってくるため、`SYMBOL_DY` などの長さもすべて図寸 mm で指定します。縮尺は `hs` 行から読み取ってログに出しますが、変換には使いません。

文字列を書き換えたとき（面積表記の削除など）は、文字データが持つ長さの値も取り直しています。これをしないと Jw_cad 側で文字が引き伸ばされます。

扱う要素は**線・点・円弧・文字**だけです。ソリッドやブロック図形は複写されず、ログに個数が出ます。

## 動作確認

`dist/テスト/天伏図テスト実行.bat` を実行すると、サンプルの座標ファイルを処理して結果をメモ帳で表示します。サンプルには「事務室」「相談室(9.94㎡)」「ﾎｰﾙ」「倉庫①」など書き方の違う室名が入れてあり、どれも拾えることを確かめられます。

実行するたびに `jww_ceiling_plan.log` が作られ、いくつ読み込んで、いくつ落として、いくつ記号を置いたかが記録されます。うまく動かないときはまずこれを見ます。

## 注意事項

- 範囲選択で「文字を含む」にチェックを入れてください。室名を拾えないと記号が書かれません。
- 寸法図形やブロック図形は、範囲選択に含めると分解されることがあります。
- 結果がおかしいときは Jw_cad の **[戻る]** で元に戻せます。
- 動作には Ruby が必要です。追加インストールを避けたい場合は、同梱の「文字位置揃え」と同じく VBScript で書き直す必要があります。
