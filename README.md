# Jw_cad 外部変形

Jw_cad Version 8.20 で動作確認済みの外部変形です。VBScript（`cscript.exe`）だけで動くので、追加のインストールは不要です。

| 外部変形 | できること |
|---|---|
| [文字位置揃え](#文字位置揃え) | 範囲選択した文字の位置を、横方向(X)・縦方向(Y) それぞれ独立に指定して揃える |
| [線切断](#線切断) | 範囲選択した線を、重なっている円・円弧・曲線との交点でまとめて切断（分割）する |

## 使い方（かんたん）

1. `dist/` の中身をフォルダごと Jw_cad の外部変形フォルダ（例 `C:\jww\外変\`）にコピー
2. Jw_cad で **[その他] → [外部変形]** → 使いたい `.bat` を選ぶ

---

# 文字位置揃え

範囲選択した文字の位置を、**横方向(X)** と **縦方向(Y)** をそれぞれ独立に指定して揃えます。

Jw_cad の標準機能（範囲選択 → 文字位置・集計）では横方向の整理が中心で、縦方向を含めた一括の揃えは手数がかかります。この外部変形は横・縦を別々に指定して一度に揃えます。

## 使い方

1. Jw_cad で **[その他] → [外部変形]** → `文字位置揃え.bat` を選ぶ
2. 揃えたい文字を範囲選択 → 選択確定
3. 横方向の揃え方を番号で入力 → 縦方向の揃え方を番号で入力

| 番号 | 横方向(X) | 縦方向(Y) |
|:--:|---|---|
| 0 | 揃えない | 揃えない |
| 1 | 左揃え | 下揃え |
| 2 | 中央揃え | 中央揃え |
| 3 | 右揃え | 上揃え |
| 4 | X座標を数値指定（文字の左端） | Y座標を数値指定（文字の下端） |
| 5 | 等間隔（左端どうしを等間隔に） | 等間隔（下端どうしを等間隔に） |
| 6 | 等間隔（文字のすき間を等間隔に） | 等間隔（文字のすき間を等間隔に） |

毎回同じ揃え方をする場合は、問い合わせなしで実行される固定設定のバッチ（`文字位置揃え_左揃え.bat` など8種）を使います。

詳しい説明は [`dist/使い方.txt`](dist/) を参照してください。

## 基準にする文字を指示して揃える

「一番左」ではなく「**この文字に合わせたい**」というときは `文字位置揃え_基準文字指示.bat` を使います。範囲選択のあとに基準にしたい文字をクリックすると、指示した点に一番近い文字が基準になり、左揃え・中央揃え・右揃え（下・中央・上）はその文字に合わせて動きます。基準にした文字自身は動きません。

これは `REM #1` で点を指示させ、その座標が `hp1 x y` として座標ファイルに渡ってくるのを利用しています。

## 等間隔配置

番号 5 / 6 を選ぶと、選択した文字を等間隔に割り付けます（`文字位置揃え_横に等間隔.bat` / `文字位置揃え_縦に等間隔.bat` でも実行可）。

- **5** … 文字の左端（下端）どうしが等間隔になるように動かす
- **6** … 文字と文字のすき間が等間隔になるように動かす。文字数がバラバラでも見た目の間隔がそろう

両端の文字は動かさず、間の文字を割り付けます。文字が3個以上ないと何も起こりません。

## 揃えの基準

- **左揃え / 右揃え** … 座標ファイルが持つ文字列の実長を使うため、文字数や文字種が違っても左端・右端がそろう
- **上揃え** … 文字種の文字高さ（`hch` / `cn0`）を見て上端をそろえる
- **下揃え** … 文字の基準点（左下）をそろえる
- **中央揃え** … 選択した文字全体の外形の中心に合わせる

## 文字データの解釈について

文字データ `ch 始点X 始点Y ○ ○ "文字列` の第3・第4フィールドは、資料によって「文字列の長さ成分」と「終点座標」の2通りの説明があります。本スクリプトは読み込んだデータから**実行時に自動判定**し、どちらでも正しく動くようにしています（水平な文字なら、前者は第4=0、後者は第4=始点Y になることを利用）。

誤判定した場合は、実行後に作られる `jww_text_align.ini` の `CHFORMAT` を `auto` から `rel`（長さ成分）または `abs`（終点座標）に書き換えて固定できます。

## 注意事項

- 元の文字は `hd` で削除され、同じ内容の文字が新しい位置に書き直されます。結果がおかしいときは Jw_cad の **[戻る]** で元に戻せます。
- 寸法図形の寸法文字や、ブロック図形の中の文字は選択しないでください。
- 傾いた文字は、上下の高さを考慮せず基準点（左下）を基準に揃えます。

# 線切断

範囲選択した**線**を、重なっている**円・円弧・楕円・曲線**との交点でまとめて切断（分割）します。Jw_cad の [編集] → [線切断] は 1 本ずつの操作になりますが、これは選択した線をまとめて処理します。

## 使い方

1. Jw_cad で **[その他] → [外部変形]** → `線切断.bat` を選ぶ
2. 切断したい線と、切断の基準にする円・円弧・曲線を**まとめて**範囲選択 → 選択確定
3. 切断の基準にする要素を番号で入力

| 番号 | 切断の基準 |
|:--:|---|
| 1 | 円・円弧・楕円と、曲線属性の付いた曲線（既定） |
| 2 | 上記＋つながっている連続線（曲線とみなす） |

どちらの番号でも、**つながっていない直線どうしの交点では切断しません**。交差しているだけの2本の線はそのまま残ります。

毎回同じ基準で切る場合は、問い合わせなしで実行される `線切断_円弧で切断.bat` / `線切断_連続線でも切断.bat` を使います。

詳しい説明は [`dist/使い方_線切断.txt`](dist/) を参照してください。

## 切断の判定

- **円弧・楕円弧** は、実際に描かれている角度の範囲だけが基準になります。円弧を延長した先では切れません。
- **楕円・楕円弧** は、楕円を円に戻す座標系（中心へ平行移動 → 傾きぶん逆回転 → Y を扁平率で割る）に線を写して交点を求めています。線の媒介変数はこの変換で変わらないので、求めた値をそのまま元の線の切断位置として使えます。
- **曲線** は線の集まりとして座標ファイルに渡ってくるため、曲線属性（`cs` 〜 `ce`）で囲まれた線を切断の基準として扱い、その線自身は切断しません。
- **連続線**（番号 2）は、曲線属性が付いていない曲線を拾うためのものです。**端点が一致している線どうし**を連続線とみなします。座標ファイルでの並び順は見ません（曲線の線が並んで書き出されるとは限らず、間に別の線が書き出されることがあるため）。つながっていない直線は、番号 2 でも切断の基準になりません。
- 線に**接している**だけの円でも、その接点で切断します。
- 交点が線の端に近すぎるときは、長さ 0 の線ができてしまうので切断しません。この「近すぎる」長さは `jww_cut_line.ini` の `TOL`（初期値 0.0001）で変えられます。

切断される図形と交わらなかった要素（円・文字・点など）は、読み込んだ行をそのまま書き戻します。

## 注意事項

- 切断されるのは線データだけです。円・円弧・曲線・文字は切断されません。
- 選択した図形はいったん `hd` で削除され、同じ図形が書き直されます。結果がおかしいときは Jw_cad の **[戻る]** で元に戻せます。
- 切断された線は元の線のレイヤ・線色・線種を引き継ぎます。
- 寸法図形・ブロック図形・ソリッドは選択しないでください。
- 線が円周と重なっている（同じ位置に乗っている）場合や、平行な線どうしは切断できません。交わっている場合だけが対象です。

# 開発

## ファイル構成

```
src/     編集用の原本（UTF-8 / LF）
dist/    そのまま使える実体（CP932 / CRLF）  ← Jw_cad に入れるのはこちら
tools/   src → dist の変換スクリプトと ZIP 作成スクリプト
```

Jw_cad はバッチファイルの `REM` 行と `jwc_temp.txt` を Shift_JIS で読み書きするため、配布する実体は CP932 + CRLF である必要があります。リポジトリ上で読みやすいよう原本は UTF-8 で持ち、次のコマンドで変換します。

```sh
python3 tools/build.py      # src → dist
python3 tools/make_zip.py   # dist → 配布用 ZIP
```

## 仕組み

```
Jw_cad ──① 選択したデータを jwc_temp.txt に出力
        └─② バッチファイルを起動
              └─③ VBScript が jwc_temp.txt を書き換える
        ──④ jwc_temp.txt を読み戻して作図
```

バッチファイルの制御行:

| 制御行 | 意味 |
|---|---|
| `REM #jww` | jww 形式の座標ファイルを受け取る（この行が無いと外部変形の一覧に出ない） |
| `REM #h1` | 範囲内の**図形データ**を `jwc_temp.txt` に書き出す（線切断） |
| `REM #h3` | 範囲内の**文字データだけ**を `jwc_temp.txt` に書き出す（文字位置揃え） |
| `REM #hc …` | 範囲選択時に表示するメッセージ |
| `REM #1 …` | 点を指示させる。指示点は `hp1 x y` として渡される（基準文字指示用のバッチのみ） |
| `REM #e` | 制御文字列の終わり |

出力する `jwc_temp.txt`:

- 先頭に `hd` を書いて、選択された元のデータを削除する
- 続けて、書き換えたデータと、元の属性行（`ly` / `lc` / `lt` / `cn` など）をそのまま出力する
- 実行済みの印として、読み込んだ `hq` などの図面情報行は出力しない
- 中止するときは `he メッセージ` だけを書く。図面は一切変更されない

`REM` 行の説明文に `#` を書くと Jw_cad が制御文字列として解釈してしまうため、バッチファイルのコメントには `#` を使っていません。

## 動作確認

`dist/テスト/` の中のバッチを実行すると、サンプルの座標ファイルを処理して結果をメモ帳で表示します。Jw_cad の図面を触らずに動作を確認できます。

| バッチ | 内容 |
|---|---|
| `テスト実行.bat` | 文字位置揃え（通常） |
| `テスト実行_基準文字.bat` | 文字位置揃え（基準文字を指示した場合） |
| `テスト実行_線切断.bat` | 線切断 |
