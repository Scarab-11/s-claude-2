# 画面キャプチャ → PDF（s2pdf）

画面の指定した範囲を連続でキャプチャし、キーを送ってページを送り、撮った連番画像を 1 つの PDF にまとめる Windows 向けツールです。

自分で作った資料、自炊済みのファイル、パブリックドメイン作品など、**複製が許可されているもの**を対象に使ってください。

## できること

- ドラッグで選んだ範囲だけを撮る（マルチモニタ・DPI 拡大にも対応）
- 指定したウィンドウを前面に出してからページ送りキーを送る
- **他の作業と並行できるモード**（ウィンドウの中身を直接撮るので、裏に回っていても撮れる）
- ページ数を決めて撮る／終端を自動で判定して止まる
- 周囲の余白を自動で切る、グレースケール化、横幅を縮小
- 連番画像を PDF に結合（無劣化 / JPEG 再圧縮でサイズ削減）
- 途中で中止（Esc）、続きから再開、失敗したページだけ撮り直し
- 設定をプロファイルとして保存して次回そのまま使う

## CLI 版と GUI 版の違い

同じ処理エンジンを使っているので、**できることは同じ**です。操作の仕方だけが違います。

| | GUI 版 | CLI 版 |
|---|---|---|
| 起動 | `キャプチャPDF_GUI.bat` をダブルクリック | `s2pdf.bat run ...` |
| 範囲の指定 | ボタンを押してドラッグ、プレビューで即確認 | `s2pdf pick` でドラッグ、または `--region 100,120,800,1200` と数値で指定 |
| 設定の変更 | 入力欄とチェックボックス | コマンドラインオプション |
| 実行中の様子 | 進捗バーつきの小窓（撮影範囲を避けて表示） | ターミナルにテキストで進捗 |
| 中止 | 「中止」ボタン / Esc | Esc / Ctrl+C |
| 向いている場面 | 初めて使うとき、範囲を試行錯誤するとき | 同じ設定を繰り返すとき、バッチファイルに組み込むとき |
| 覚えること | ほぼ不要 | オプション名 |

**迷ったら GUI 版**を使ってください。範囲選びとプレビュー確認は目で見た方が早く、一度 GUI で設定を保存しておけば、同じ設定を CLI 側からも `--profile` で呼び出せます。

## セットアップ

Python 3.9 以降が必要です（[python.org](https://www.python.org/) の Windows 版インストーラを使う場合、tkinter は標準で入ります）。

1. このフォルダを丸ごとコピーする
2. `初回セットアップ.bat` をダブルクリック（`pip install -r requirements.txt` が走ります）

必要なライブラリは `Pillow`、`mss`、`img2pdf` の 3 つです。

## GUI 版の使い方

`キャプチャPDF_GUI.bat` を実行します。

1. **キャプチャ範囲** … 「範囲を選ぶ」→ 画面が暗くなるのでドラッグで囲む → 「プレビュー」で仕上がりを確認
2. **ページ送り** … 「対象ウィンドウ」を選び（一覧は自動で読み込まれます。無ければ名前の一部を直接入力しても可）、送るキー（`right` など）とページ数を決める
   - ページ数を **0** にすると、画面が変わらなくなった時点で自動的に終わります
3. **画像の保存と加工** … 保存先フォルダ、余白除去、グレースケール、縮小
4. **PDF** … 出力ファイル名。「撮影後に自動で PDF を作る」を入れておけば撮り終わりと同時に PDF になります
5. **実行** … 「開始」。指定秒後に始まり、本体ウィンドウは自動で隠れます

止めたいときは進捗小窓の「中止」か、**Esc キー**（他のウィンドウを操作中でも効きます）。

失敗したページがあったら、そのページを画面に出した状態で「このページを撮り直す」に番号を入れて「撮る」を押すと、その 1 枚だけ差し替わります。差し替えたあと「画像フォルダから PDF を作る」で PDF を作り直してください。

## CLI 版の使い方

```
s2pdf.bat pick                          範囲をドラッグで選んでプロファイルに保存
s2pdf.bat preview                       いまの範囲を 1 枚だけ撮って preview.png に保存
s2pdf.bat run --pages 120               120 ページ撮る
s2pdf.bat run --pdf book.pdf            撮り終えたらそのまま PDF にする
s2pdf.bat run --resume                  既にある画像の続きから撮る
s2pdf.bat shot --index 37               37 ページ目だけ撮り直す
s2pdf.bat build capture -o out.pdf      画像フォルダから PDF を作る
s2pdf.bat windows                       開いているウィンドウの一覧
s2pdf.bat profiles                      保存済みの設定を見る
s2pdf.bat doctor                        必要なライブラリが入っているか調べる
```

よく使うオプション（`run` / `preview` / `shot` 共通）:

| オプション | 意味 |
|---|---|
| `--region 左,上,幅,高さ` | 範囲を数値で指定 |
| `--window タイトル` | キーを送るウィンドウ（部分一致） |
| `--window-capture` | ウィンドウを直接撮る（他の作業と並行できる。`--window` が必要） |
| `--screen-capture` | 画面をそのまま撮る（既定に戻す） |
| `--key right` | ページ送りに使うキー |
| `--pages 120` | 撮るページ数（`0` で終端の自動判定） |
| `--out-dir capture` | 画像の保存先 |
| `--format png\|jpg` | 画像形式 |
| `--settle-delay 0.8` | ページ送り後、描画が落ち着くまでの待ち時間（秒） |
| `--trim` / `--no-trim` | 周囲の余白を切る／切らない |
| `--grayscale` | グレースケールにする |
| `--max-width 1600` | 横幅をここまで縮小する |
| `--no-auto-stop` | 画面が変わらなくても止めない |
| `--profile 名前` | 使う設定プロファイル |
| `--save` | 今回の指定をプロファイルに保存 |

`build` では `--dpi 150`（PDF の解像度）と `--jpeg-quality 60`（再圧縮してファイルを小さくする。省略すると無劣化）が使えます。

設定は `%APPDATA%\s2pdf\profiles.json` に保存されます。

## 撮り方は 2 種類あります

| | 画面をそのまま撮る（既定） | ウィンドウを直接撮る |
|---|---|---|
| 仕組み | 画面の指定座標をそのまま取り込む | ウィンドウ自身に描画させて取り込む（PrintWindow） |
| キーの送り方 | 対象を前面に出してから送る | 前面に出さずにメッセージで送る |
| 実行中に他の作業 | **できない**（別のウィンドウを前に出すと、それが写る） | **できる**（裏に回っていても撮れる） |
| 対応するアプリ | ほぼすべて | アプリによる |
| 指定方法 | 既定 | GUI: 「他の作業と並行する」にチェック<br>CLI: `--window-capture --window "タイトル"` |

「ウィンドウを直接撮る」は、アプリの描画方法によっては真っ黒な画像しか返りません。開始前に自動で判定し、駄目な場合はその場でエラーになるので、実行して確かめてください。

このモードでは、キャプチャ範囲は**ウィンドウの左上を原点とした座標**で保存されます。ウィンドウを動かしても同じ場所を撮り続けられますが、**ウィンドウの大きさを変えると撮る位置がずれる**ので、途中でサイズを変えないでください。撮り方を切り替えたときは範囲を選び直す必要があります（座標の意味が変わるため）。

範囲を指定しなければウィンドウ全体を撮ります。

## 2 つ目以降を撮るとき

画像は保存先フォルダに溜まっていき、PDF はそのフォルダの中身**全部**をまとめます。そのため、前回の画像が残ったまま次を撮ると 1 つの PDF に混ざります。

これを防ぐため、**前回の画像が残っているフォルダに撮ろうとすると確認が出ます**。

GUI では「開始」を押した時点で 3 つの選択肢が出ます:

| 選択肢 | 動作 |
|---|---|
| 別のフォルダに保存する（おすすめ） | `capture` → `capture_2` のように連番のフォルダを作る。PDF 名も同名があれば `book_2.pdf` にずらす |
| 今ある画像を削除してから撮る | 前回の画像を消して撮り直す |
| 前回の続きとして追加する | わざと 1 つの PDF にまとめたいとき |

CLI では既定で中止し、やり方を案内します。指定して動かす場合:

```
s2pdf.bat run --on-existing new     連番の別フォルダにする
s2pdf.bat run --on-existing clear   削除してから撮る
s2pdf.bat run --on-existing append  そのまま追加する
s2pdf.bat run --out-dir book2 --pdf book2.pdf   保存先を自分で決める
```

「続きから」（`--resume`）を指定しているときは、混ざるのが目的なので確認は出ません。

## 設定のコツ

- **`--settle-delay`（ページ送り後の待ち）** … これが短すぎると前のページや描画途中を撮ってしまいます。まず `1.0` 秒くらいで試し、問題なければ短くしてください。
- **終端の自動判定** … 同じ画面が 3 回続いたら終わりとみなします（`duplicate_limit`）。最後に撮れた重複分は自動で削除されます。アニメーションのように毎回わずかに変わる画面では止まらないので、その場合はページ数を指定してください。
- **余白除去** … 四隅の色を背景色とみなして、そこから離れた部分の外接矩形で切ります。ページごとに切る量が変わるので、PDF のページサイズを揃えたいときは使わないでください。
- **ファイルサイズ** … 文字中心なら `--grayscale` と `--max-width` が効きます。写真中心なら `build --jpeg-quality 60` の方が効きます。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「mss が入っていません」と出る | `初回セットアップ.bat` を実行してください。それでも出る場合は `s2pdf.bat doctor` を実行すると、**どの Python に**入れればよいかがコマンドごと表示されます（Windows は Python が複数入っていて、別の Python に入れてしまっていることがよくあります） |
| 2 つ目が 1 つ目と混ざる | 保存先フォルダを分けてください。開始時に確認が出るので「別のフォルダに保存する」を選びます（[2 つ目以降を撮るとき](#2-つ目以降を撮るとき)） |
| 対象ウィンドウの欄に何も出てこない | 一覧は起動時と、欄を開いたときに自動で読み込まれます。それでも目的のアプリが出ない場合は、**欄に名前の一部を直接入力**しても指定できます（部分一致）。`s2pdf.bat windows --all` を実行すると、絞り込みなしの全ウィンドウ名を確認できます |
| 実行中に他の窓を開くと止まる／その画面が写る | 「画面をそのまま撮る」モードは、画面に見えているものをそのまま撮ります。別のウィンドウを前に出すとそれが写り、同じ画面が続いたと判定されて自動停止します。**「ウィンドウを直接撮る」モードに切り替えてください**（`--window-capture`）。対応していないアプリの場合は、実行中は触らずに待つしかありません |
| 撮れる範囲がずれる | 拡大率 100% 以外の環境では、範囲を選び直してください（DPI 対応は自動で行いますが、選択と実行の間で拡大率を変えるとずれます） |
| ページが送られない | `--window` で対象ウィンドウを指定してください。指定がないと、前面にあるウィンドウにキーが送られます |
| 前のページが写る | `--settle-delay` を長くしてください |
| 途中で止まってしまう | 同じ画面が続いたと判定されています。`--no-auto-stop` を付けるか、`--pages` でページ数を指定してください |
| 自分のウィンドウが写り込む | GUI 版は実行中に自動で隠れます。進捗の小窓が範囲にかかる場合は、範囲を選び直すか CLI 版を使ってください |
| 撮った画像が黒い・真っ白 | 保護されたコンテンツを表示しているアプリは、そもそもキャプチャできない作りになっていることがあります。そういうアプリはこのツールの対象外です |

## 開発

```
python -m pytest tests -q
```

`tests/` は画面キャプチャとキー送出を差し替えて動かすので、Windows 以外でも実行できます。tkinter や画面が無い環境では GUI 関連のテストは自動でスキップされます。

構成:

| ファイル | 役割 |
|---|---|
| `s2pdf/engine.py` | キャプチャのループ本体（CLI・GUI 共通） |
| `s2pdf/imaging.py` | 余白除去・縮小・同一ページ判定 |
| `s2pdf/pdfbuild.py` | 連番画像 → PDF |
| `s2pdf/region.py` | ドラッグで範囲を選ぶオーバーレイ |
| `s2pdf/winput.py` | Windows のキー送出・ウィンドウ操作・DPI 設定 |
| `s2pdf/config.py` | 設定（プロファイル）の保存と読み込み |
| `s2pdf/cli.py` / `s2pdf/gui.py` | それぞれの入口 |
