# 室の自動検出：検証結果

壁芯線（一点鎖線・専用レイヤ）から室を検出できるかを、実データで検証した記録です。

- `jwc_dump_plan.txt` … Jw_cad の外部変形で書き出した平面図のダンプ（実データ）
- `room_detect_prototype.py` … 検出の試作。`python3 room_detect_prototype.py` で結果が出ます

## 図面側のレイヤ構成（ダンプから判明）

| レイヤ | 内容 |
|---|---|
| 1 | 通り芯（線色1・一点鎖1）＋通り芯記号（線色4・実線）＋記号文字 |
| 2 | 室名・面積表記・家具名 |
| 3 | 寸法 |
| 8 | 建具ほか |
| a | 設備・階段ほか |
| d | 図面名 |
| e | **天井高（`ch=2500` 形式）** |
| **f** | **壁芯線（線色4・一点鎖1）18本** |

## 検出結果

壁芯線18本 → 節点27・辺36 → **閉領域10個**。面積は図面の表記と完全に一致しました。

| 検出面積 | 室名 | 天井高 | 判定 |
|---:|---|---|---|
| 10.45㎡ | 事務室 | 2700 | ○ |
| 9.94㎡ | 相談室 | 2700 | ○（図面表記 9.94㎡ と一致） |
| 8.92㎡ | － | － | 室名・天井高なし → 対象外 |
| 7.85㎡ | 洋室-1 | 2500 | ○（図面表記 7.85㎡ と一致） |
| 4.01㎡ | － | 2700 | 室名なし（事務室玄関） |
| 2.48㎡ | 倉庫① | 2500 | ○（図面表記と一致） |
| 2.48㎡ | 倉庫② | 2500 | ○（図面表記と一致） |
| 2.10㎡ | WC | 2500 | ○ |
| 1.43㎡ | 収納 | 2500 | ○ |
| 0.83㎡ | － | － | 室名・天井高なし → 対象外 |

**7室が完全に自動で確定**しました。

## 展開面の自動生成

検出した多角形から Ａ〜Ｄ面を生成できることも確認しました。洋室-1 は、PDF から手作業で起こした結果と完全に一致します。

```
■ 洋室-1  天井高 2500（検出面積 7.85㎡）
   Ａ面  幅 3640
   Ｂ面  幅 2550 ＝ 980 ＋ 1570
   Ｃ面  幅 3640 ＝ 910 ＋ 2730
   Ｄ面  幅 2550
```

面の並び順は Ａ(北を見る)=X昇順 / Ｂ(東)=Y降順 / Ｃ(南)=X降順 / Ｄ(西)=Y昇順。
T字接合で分割された辺は、同一平面どうしをつないでから段差を判定します。

## 残る課題

1. **室名レイヤに家具名・面積表記が混在**（`ｶｳﾝﾀｰ`、`(2.48㎡)`）。
   面積表記を除外し、天井高テキストに最も近い文字を室名とする規則で7室とも正解しましたが、
   室名専用レイヤに分けるほうが確実です。
2. **室名または天井高が無い領域**は対象外になります（玄関・ホール・廊下、事務室玄関、洋室-1下の収納）。
