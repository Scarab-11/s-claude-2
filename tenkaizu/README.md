# 展開図（洋室-1 / 事務室）　A3　S=1/100

1階平面図（PDF）から起こした展開図です。各室 A・B・C・D の4面、計8面。

## ファイル

| ファイル | 内容 |
|---|---|
| `gaibu/`（`展開図_外部変形.zip`） | **外部変形版（推奨）**。Jw_cad 上で確実にレイヤ1〜4に振り分けて作図し、`.jww` で保存できます |
| `tenkaizu.dxf` | DXF R12。Jw_cad の「DXFファイルを開く」で読めます |
| `preview.pdf` / `preview.png` | 出来上がりの確認用 |
| `tenkaizu_gen.py` | 生成スクリプト。室・面・寸法を差し替えて再生成できます |

### `.jwc` を出力しない理由

実物の `.jwc` を確認したところ、**バイナリ形式**でした。先頭に `jw_cad(c)data` の署名があり、
ヘッダは `4000:0000,4000:02cb,…` のような DOS のセグメント:オフセット表記を含み、
図形は「32bit float ×4（x1,y1,x2,y2）＋属性6バイト」の 22 バイト固定長レコードが並びます。

`hs 100` / `ly1` / `ch …` といったテキスト形式は **外部変形の受け渡し用（jwc_temp.txt）** であって
`.jwc` ファイルの形式ではありません。テキストを `.jwc` として保存しても Jw_cad は受け付けません。

`.jww` は外部変形で作図してから保存すれば得られるので、バイナリ `.jwc` を書き起こす必要はありません。

### 外部変形版の使い方

1. `gaibu/` の中身（`展開図作図.bat` / `tenkaizu_draw.vbs` / `tenkaizu_data.txt`）を
   まとめて Jw_cad の外部変形フォルダ（例 `C:\jww\外変\`）にコピー
2. 用紙 A3、**書込レイヤグループの縮尺を 1/100** にする
3. **[その他] → [外部変形]** → `展開図作図.bat` を選ぶ
4. 「展開図を配置する位置（左下）を指示してください」と出るので、置きたい位置をクリック

指示した点が図面全体の左下になります。レイヤ1〜4への振り分けはデータ側で持っているので、
DXF のようにレイヤが入れ替わることはありません。

## 壁仕上面の寄り（WALL_T = 80）

**枠線は基準線から 80mm 内側**に描いています（`tenkaizu_gen.py` の `WALL_T`）。
寸法はすべて芯々（基準線間）のままなので、枠線の幅は「芯々 − 160」になります。

段差のある面では、壁面が切り替わる位置に枠線を1本入れています。
その位置は壁芯から 80mm ずれるため、**壁芯には基準線（記号なしの一点鎖線）を別途引き**、
内訳寸法はその基準線間（芯々）で測っています。
例：洋室-1 Ｂ面は基準線が 0 / 980 / 2,550、枠線は 80〜2,470、段差線は 900。

## レイヤ分け

| レイヤ | 内容 | 線色 | 線種 |
|---|---|---|---|
| 1 | 基準線（通り芯・壁芯の一点鎖線）＝`lt5` / 通り芯記号の円・十字・文字＝`lt1`（実線） | 1 | 5 と 1 |
| 2 | 寸法線、寸法補助線、端部の点、**寸法値の文字** | 1 | 1（実線） |
| 3 | 室の枠線、段差の縦線、面記号の囲み枠 | 2 | 1（実線） |
| 4 | 室名、面記号（Ａ　面 等） | 1 | 1（実線） |

文字は**任意サイズ文字**（`cn0 幅 高さ 間隔 色`）で出しています。文字種（`cn1`〜`cn10`）の
寸法は Jw_cad 側の設定に依存し、環境によって 1.5mm などになってしまうためです。

| 用途 | 文字高 | 出力 |
|---|---|---|
| 寸法値 | 2.0mm | `cn0 200 200 0 1` |
| 通り芯記号（X1・Y4 など） | 3.5mm | `cn0 350 350 0 1` |
| 室名・面記号 | 2.5mm | `cn0 250 250 0 1` |

線種はレイヤ単位ではなく要素単位で指定しています。レイヤ1のうち
**基準線だけ `lt5`（一点鎖1）、通り芯記号の円と十字は `lt1`（実線）**です。

## 判断したところ

- 寸法値の文字はレイヤ2（寸法線と同じ）。参考図では帰属が読み取れませんでした。
- 通り芯記号の文字は 3.5mm（ご指定）。参考図の実測は約1.9mmでしたが指定を優先しました。
- 面記号の囲み枠はレイヤ3（枠線）、中の文字はレイヤ4（文字）。
- 通り芯に載らない側にも基準線は引き、記号は付けていません。

## 文字データ（ch）の書式

```
ch 始点X 始点Y 文字列の長さX 文字列の長さY "文字列
```

第3・第4フィールドは**終点座標ではなく文字列の長さベクトル**です。
`src/テスト/sample_jwc_temp.txt` の `ch 100 200 13.5 0 "あいうえ` が
文字種3（幅3.0・間隔0.5）で全角4文字ぶん＝ 4×3 ＋ 3×0.5 ＝ 13.5 になっています。

横書きは `長さ 0`、下から上へ読む縦書きは `0 長さ`。
長さは実寸なので「用紙上の長さ × 縮尺分母」で計算します（文字種1で半角2文字なら 2.0mm → 200）。

ここを終点座標で書くと、**文字が全て斜めに描かれます**。
`tenkaizu_draw.vbs` の平行移動でも、第3・4は長さなので始点だけを移動します。
