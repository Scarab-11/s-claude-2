# 展開図 自動作図（外部変形）

平面図を範囲選択すると、**壁芯の一点鎖線から室を検出して、各室の Ａ〜Ｄ面の展開図を自動作図**します。

## 入れ方

`展開図_自動作図.bat` / `tenkaizu.py` / `tenkaizu_setting.txt` の3つを、
Jw_cad の外部変形フォルダ（例 `C:\jww\外変\`）に**同じフォルダで**コピーします。

Python 3.8 以上が必要です（`py` ランチャー経由で呼びます）。追加ライブラリは不要です。

## 使い方

1. **作図先レイヤグループ（既定はグループ1）の縮尺を 1/100 にしておく**
2. **[その他] → [外部変形]** → `展開図_自動作図.bat`
3. 「平面図全体を範囲選択してください」→ 範囲選択
4. 「展開図を配置する位置（左上）を指示してください」→ クリック
5. 作図されます

平面図は削除されません（先頭に `hd` を出さないため）。

## 平面図側に必要なもの

| | 内容 | 既定レイヤ | 要否 |
|---|---|---|---|
| 壁芯線 | **すべての壁**に一点鎖線を引く。壁のある範囲だけ | **f** | 必須 |
| 室名 | 室名を描いているレイヤ | **d** | 必須 |
| 天井高 | `ch=2500` の形式で室内に書く | **e** | 必須 |
| 通り芯 | X1・Y2 などの記号があるレイヤ（記号を拾うのに使用） | **1** | 任意 |
| 巾木高さ | `巾木60` の形式で室内に書く | **c** | 任意 |
| 腰壁高さ | `腰壁1100` の形式で室内に書く | **b** | 任意 |

レイヤ番号は `tenkaizu_setting.txt` で変更できます。室名を専用レイヤに移したら
`室名レイヤ` をその番号に変えてください。

室名レイヤに家具名などが混ざっていても動きます。

- **「(7.85㎡)」のような括弧付きの文字は自動で除外**されます
- それ以外は `室名から除外=ｶｳﾝﾀｰ,カウンター` にカンマ区切りで並べてください
- 同じ室に候補が複数残った場合は、天井高の文字に最も近いものを室名とします

**室名と天井高が両方ある室だけ**が作図対象です。展開図が不要な領域には書かないでください。

### 巾木

室内に **`巾木60`**（数字は mm）と書いておくと、その室の Ａ〜Ｄ面すべてに、
**床から 60mm の高さ**へ横線を1本引きます。室ごとに高さを変えられます。

- 書いていない室には引きません。**巾木レイヤが空でもエラーにはなりません**
- 数字以外は読み飛ばすので `巾木＝60` `巾木 60` でも同じです
- 接頭辞は `巾木の接頭辞=巾木`、作図先は `レイヤ_巾木=6` / `線色_巾木=1` で変更できます
- 線は壁の仕上面から仕上面まで（外形線と同じ幅）引きます

### 腰壁

室内に **`腰壁1100`**（数字は mm）と書いておくと、その室の Ａ〜Ｄ面すべてに次の3つを描きます。

1. **床から 1100mm** に横線（腰壁の天端）
2. その **25mm 下** に横線（見切り下端線）
3. **見切り下端線と巾木の間**に縦線を **110mm ピッチ**で（面の左端から 110mm ごと）

```
──────────────  腰壁天端      1100
──────────────  見切り下端線  1075
 │ │ │ │ │ │ │   縦線 @110
──────────────  巾木           60
──────────────  床              0
```

- 25mm は `腰壁の見切り厚`、110mm は `腰壁の縦線ピッチ` で変更できます。
  **ピッチを `0` にすると縦線を入れません**
- 巾木を書いていない室では、縦線は**床から**見切り下端線までになります
- 書いていない室には描きません。**腰壁レイヤが空でもエラーにはなりません**
- 作図先は `レイヤ_腰壁=7` / `線色_腰壁=1` で変更できます

### 壁芯線の注意点

- 他レイヤの通り芯と**重なっていても問題ありません**
- 交点を少し**行き過ぎても問題ありません**（宙ぶらりんの端は無視されます）
- **壁のない位置を通る線が室を横断すると、その室が2つに割れます**。通り芯をコピーして作る場合は、壁のない区間を切り取ってください

## 動作

1. 壁芯線を交点で分割してつなぎ、閉じた領域＝室を検出
2. 領域内の文字から室名・天井高・巾木高さ・腰壁高さを取得
3. 多角形から Ａ（北を見た面）・Ｂ（東）・Ｃ（南）・Ｄ（西）を生成
   - T字接合で分かれた辺は、同じ壁面どうしをつないでから段差を判定
   - 段差線は壁芯から `壁の寄り` ぶん、奥行の深い側へ寄せます
   - **面の幅は壁の長さの合計ではなく、面の軸に投影した和集合**です。
     したがって **Ａ・Ｃ面が室のX方向の全長を、Ｂ・Ｄ面がY方向の全長を超えることはありません**
4. **1段に1室**（Ａ〜Ｄの4面）ずつ並べ、**指示点を左上**として作図（そこから右下へ広がります）

## 配置

**1段に1室**です。Ａ・Ｂ・Ｃ・Ｄが横一列に並び、次の室から段が変わります。

横に長い室で1段に入りきらないときだけ、その室の途中で段を分けます。
判定は `折り返し幅=30000`（実寸mm。1/100 なら用紙上 300mm）。

- 面と面のすきまは `面の間隔_横=1500`、段と段は `面の間隔_縦=1500`
- 1段に複数室を詰めたいときは `室ごとに改行=しない` に戻してください

室数が多いと縦に伸びて A3 に収まらなくなります。収まらない場合は
`tenkaizu_log.txt` にその旨と全体寸法が出るので、用紙を大きくするか
`面の間隔_縦` を詰めてください。

## 検証結果

実際の平面図（`../kenshou/jwc_dump_plan.txt`）で確認しています。

- 壁芯線18本 → 閉領域10個。面積は図面表記と完全一致
- 室名と天井高が揃った **7室・28面** を自動作図
- 洋室-1 は、PDF から手作業で起こした結果と完全一致

このダンプは室名がレイヤ2・巾木も腰壁もない古い図面なので、上のレイヤ構成で試すときは
室名をレイヤ d へ移し、`巾木60` をレイヤ c、`腰壁1100` をレイヤ b に足してください。
移した図面で、巾木・腰壁が書かれた室にだけ描かれること、
腰壁の縦線が巾木（無ければ床）から見切り下端線まで 110mm ピッチで入ることを確認しています。

```
■ 洋室-1  天井高2500
   Ａ面 3640 [X1〜X2]
   Ｂ面 2550 ＝ 980 ＋ 1570 [Y2〜－]
   Ｃ面 3640 ＝ 910 ＋ 2730 [X2〜X1]
   Ｄ面 2550 [－〜Y2]
```

`preview_sample.png` が28面の出来上がりです（A3内に収まります）。

## うまくいかないとき

Jw_cad が「未実行」と表示したら、Python 側が `jwc_temp.txt` を書き換えられずに終わっています。
**図面は変更されていません**（`hq` が残るため Jw_cad が何もしません）。

原因は同じフォルダにできる **`tenkaizu_log.txt`** に記録されます。失敗時はメモ帳で自動的に開きます。
ログには次が載ります。

- Python のバージョンと、`jwc_temp.txt` を見つけた場所
- **受け取ったデータのレイヤ別集計**（どのレイヤに線・文字が何個あるか）
- 壁芯線・室名・天井高の抽出結果
- 検出した閉領域と、それぞれの室名・天井高の有無

よくある原因は次のとおりです。

| ログの表示 | 対処 |
|---|---|
| 室名レイヤ「d」に文字がありません | 室名をレイヤ d に移すか、`tenkaizu_setting.txt` の `室名レイヤ` を実際の番号に変える |
| 巾木・腰壁が引かれない | ログの「巾木(レイヤc)」「腰壁(レイヤb)」の個数を確認。0個ならレイヤの指定違いか、文字が室の外にある |
| 壁芯線レイヤ「f」に線がありません | 同上（`壁芯線レイヤ`） |
| 閉領域が少ない／室名が(なし) | 壁芯線が閉じていない、または室名・天井高が書かれていない |
| Python が見つかりません | コマンドプロンプトで `py --version` が動くか確認 |

「受け取ったデータ」のレイヤ別集計を見れば、実際にどのレイヤに何があるかが分かります。

## 限界

- コの字型・工の字型のように**同じ向きの壁が前後2枚ある室**は、どちらの壁を描くかが
  一意に決まりません。**遠い側（室の外形をなす方）の壁**で作図し、
  `tenkaizu_log.txt` に次のように記録します。手前の壁を描きたい場合は手で直してください。

  ```
  ※ 事務室 Ｂ面 : 同じ向きの壁が前後2枚あります（重なり 1820 mm）。遠い側の壁で作図しました。
  ```
- 傾いた壁は未対応（直交する壁のみ）
- 天井高が図面にない室は対象外です
