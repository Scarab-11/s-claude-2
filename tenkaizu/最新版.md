## 外部変形版とEXE版は、同じZIPから両方できます

**ダウンロードするファイルは上の2つだけ**です。EXE版は別のダウンロードではなく、
同じZIPに入っている `exe作成.bat` から作ります。

```
ZIPを展開する
   ├─ そのまま使う              → 外部変形版（自分のPC用。Pythonが要る）
   └─ exe作成.bat をダブルクリック → EXE版（配布用フォルダができる。相手にPythonは不要）
```

実行用バッチは**exeがあればexeを、無ければ .py を呼ぶ**ので、バッチは1本のままです。

### ZIPの中身

| 展開図_自動作図.zip | 仕上表_縦組み.zip | |
|---|---|---|
| `展開図_自動作図.bat` | `仕上表_縦組み.bat` | Jw_cadから呼ぶ本体 |
| `tenkaizu.py` | `shiage.py` | 中身 |
| `tenkaizu_setting.txt` | `shiage_setting.txt` | 設定（メモ帳で編集） |
| `exe作成.bat` | `exe作成.bat` | EXE版を作る |

## 使う前に必ず確認すること

**作図先レイヤグループの縮尺**。ここが違うと、エラーにならずに変な大きさで描かれます。

| ツール | 作図先グループ | 縮尺 |
|---|---|---|
| 展開図 自動作図 | **1** | **1/100** |
| 仕上表 縦組み | **E** | **1/100** |

## 平面図・概要表の側で必要なもの

**展開図 自動作図**

| | レイヤ | 要否 |
|---|---|---|
| 壁芯線（一点鎖線） | f | 必須 |
| 室名 | d | 必須 |
| 天井高（`ch=2500` の形） | e | 必須 |
| 通り芯 | 1 | 任意 |
| 巾木（`巾木60` の形） | c | 任意 |
| 腰壁（`腰壁1100` の形） | b | 任意 |

**仕上表 縦組み** … 縦横の罫線が引かれた表であること。見出し行ごと範囲選択します。
表以外の長い線が選択に入ると読めなくなるので、表を専用レイヤに置いて `表レイヤ` に
その番号を入れておくと確実です。

## うまくいかないときに見るもの

バッチと同じフォルダにできるログです。失敗したときはメモ帳で自動的に開きます。

| ツール | ログ |
|---|---|
| 展開図 自動作図 | `tenkaizu_log.txt` |
| 仕上表 縦組み | `shiage_log.txt` |

どのレイヤに線と文字が何個あったか、何を読み取ったかが全部出ます。
**失敗しても図面は変更されません**（`hd` を出さない作りのため、選択した図形も消えません）。
