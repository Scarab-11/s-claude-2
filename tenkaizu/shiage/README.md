# 仕上表 縦組み（外部変形）

横長の**内部仕上概要表を範囲選択**すると、罫線から表を読み取って、
**1室ぶんずつ縦組みの仕上表**（床・巾木・腰壁・壁・天井・備考）を作図します。

A3用紙に**縦一列で5枠**並べ、6室目からは**用紙をそのまま下へ足して**いきます。

## 入れ方

`仕上表_縦組み.bat` / `shiage.py` / `shiage_setting.txt` の3つを、
Jw_cad の外部変形フォルダ（例 `C:\jww\外変\`）に**同じフォルダで**コピーします。

Python 3.8 以上が必要です（`py` ランチャー経由で呼びます）。追加ライブラリは不要です。

## 使い方

1. **作図先レイヤグループ（既定はグループE）の縮尺を 1/100 にしておく**
2. **[その他] → [外部変形]** → `仕上表_縦組み.bat`
3. 「内部仕上概要表を範囲選択してください」→ 表を**見出し行ごと**範囲選択
4. 「仕上表を配置する用紙の左上を指示してください」→ クリック
5. 作図されます

指示した点が**1枚目の用紙の左上**になります（そこから右下へ広がります）。
元の概要表は削除されません（先頭に `hd` を出さないため）。

## 元の表に必要なもの

**縦横の罫線が引かれた表**であること。それだけです。列の並びや室の数は自由です。

| | 内容 |
|---|---|
| 見出し行 | 表のいちばん上の行。ここの文字で列を判別します |
| 室名の列 | **「床」の列の左どなり**を室名の列とみなします |
| 室の行 | 室名が入っている行だけを1室として拾います |

見出しは `床` `巾木` `腰壁` `壁` `天井` `天井高` `廻り縁` `備考` を探します。
`巾　　木` `天　　井` のように間に空白が入っていても読めます。

- **「事務所」「1階」のような縦の結合セルは読み飛ばします**（室名の列より左にあるため）
- **一部の列だけを仕切っている罫線は、行の境界にしません**
  （例：天井高だけ `2,500(収納A)` / `2,300(収納B)` と上下に割ってある行は、1室のままです）
- 斜線で消してある欄（浴室の壁・天井など）は空欄として扱います

### 腰壁の取り出し

概要表に**腰壁の列が無くても**、壁の欄が次のように書かれていれば腰壁を分けて拾います。

```
腰壁：胴縁15×45＠303下地　PB t=12.5の上　杉板(CL) t=12.0貼り
壁：胴縁15×45＠303下地　PB t=12.5の上EP-G
```

行頭が `腰壁：` の行を**腰壁**の欄へ、それ以外を**壁**の欄へ入れ、`腰壁：` `壁：` は取り除きます。
概要表に腰壁の列があれば、そちらを優先します。取り出し元は `腰壁の取り出し元=壁` で変えられます。

## 枠の作り

```
┌────────────────────┐
│       事務室(玄関含む)      │  室名        5.5mm
├────┬───────────────┤
│    │ ｺﾝｸﾘｰﾄ下地           │
│ 床 ├───────────────┤  床  3.5mm × 2段（段ごとに仕切る）
│    │ 長尺塩ﾋﾞｼｰﾄt-2.0貼    │
├────┼───────────────┤
│    │ 木製(杉：CL)　H=60    │
│ 巾木├───────────────┤  巾木 3.5mm × 2段（同上）
│    │                     │
├────┼───────────────┤
│ 腰壁│ 胴縁15×45＠303下地… │  腰壁 7.0mm（仕切らず、行のまん中へ）
│    │ 杉板(CL) t=12.0貼り  │
├────┼───────────────┤
│ 壁 │ 胴縁15×45＠303下地… │  壁  7.0mm
├────┼───────────────┤
│ 天井│ 木軸下地             │  天井 7.0mm
│    │ 化粧石膏ﾎﾞｰﾄﾞt=9.5貼  │
├────┼───────────────┤
│ 備考│ 既製品ｶｳﾝﾀｰ・…       │  備考 2.85mm × 3行
│    │ ﾌﾞﾗｲﾝﾄﾞBOX・ﾌﾞﾗｲﾝﾄﾞ   │
│    │ 掲示板(1200×900)・…  │
└────┴───────────────┘
 8.0mm         59.5mm
 ←───────  67.5mm  ───────→        枠の高さ 49.05mm
```

- **床・巾木**は段ごとに横線で仕切り、元の表の1行目を上の段、2行目を下の段に入れます。
  1行しか無ければ下の段は空欄になります。
- **腰壁・壁・天井・備考**は仕切らず、行のまん中に寄せて書きます。
- 元の表の記述が長いときは**枠の幅に合わせて自動で折り返します**。空白があればそこで切ります。

### 枠が伸びる室

折り返しで既定の行数（`項目の行数=2,2,2,2,2,3`）を超えると、その枠だけ縦に伸びます。
そのときは**その室から下の枠を自動で押し下げて**重ならないようにし、
`shiage_log.txt` に次のように記録します。

```
※ LDK : 記述が長く枠の高さが 56.1mm（標準 49.1mm）になったため、この室から下を 7.0mm 押し下げました。
  そろえたいときは 枠幅 を広げるか 文字高 を小さくしてください。
```

高さをそろえたいときは `枠幅` を広げるか `文字高` を小さくしてください。

## レイヤと線色

作図先は `作図レイヤグループ=E`（縮尺 1/100）。設定で変えられます。

| 対象 | レイヤ | 線色 |
|---|---|---:|
| 各表の**外枠**（上下左右の4辺） | 0 | **5** |
| **室名と床のあいだ**の線 | 0 | **5** |
| 項目のあいだの横線・床/巾木の段の仕切り・見出し列の縦線 | 0 | **2** |
| 文字（室名・項目名・本文） | 1 | **6** |
| 用紙枠（`用紙枠=する` のときだけ） | 0 | 8 |

文字は任意サイズ文字（`cn0 2.5 2.5 0 6`）で出します。文字種の表に依存させず、
折り返しの計算どおりの幅で描くためです。

## 用紙への並べ方

```
用紙の左上（指示点）
 ├─ 22.0mm ─┐
 ↓14.3mm    ↓
            ┌──────┐  1室目
            └──────┘
              ↕ 52.0mm（枠ピッチ_縦）
            ┌──────┐  2室目
            └──────┘
                :          … 1枚に5枠
 ─────────────────────  用紙ピッチ_縦 = 297mm
            ┌──────┐  6室目（2枚目の1つ目）
```

- 1枚に並べる数は `1枚の枠数=5`
- 2枚目以降は `用紙ピッチ_縦=297`（A3の高さ）ぶん下へずらして並べます
- `用紙枠=する` にすると、各用紙の外形を線色8で描きます（枚数の目印。既定は描きません）

Jw_cad の用紙は1枚ぶんなので、**2枚目以降は用紙の外にはみ出した位置に描かれます**。
印刷するときは、その位置へ図面を移動するか、範囲を切り取って別図面に貼ってください。

## うまくいかないとき

Jw_cad が「未実行」と表示したら、Python 側が `jwc_temp.txt` を書き換えられずに終わっています。
**図面は変更されていません**。原因は同じフォルダにできる **`shiage_log.txt`** に記録され、
失敗時はメモ帳で自動的に開きます。ログには次が載ります。

- 受け取ったデータのレイヤ別集計
- **読み取った表の格子**（行の境界Y・列の境界X）
- **見出し行から読み取った列**と、その対応
- **室ごとの中身**（6項目それぞれ、折り返し後の状態）
- 用紙の割付と、枠を押し下げた室

| ログの表示 | 対処 |
|---|---|
| 罫線から表の格子を作れませんでした | 縦横の罫線がある表を選ぶ。罫線が図形・ブロックだと線として渡りません |
| 見出し行に「床」の列が見つかりません | 見出し行ごと範囲選択する。見出しの文字を確認する |
| 行や列が多すぎる／少なすぎる | `覆い率` を上げ下げする。既定 0.5（表の幅の半分以上ある罫線を境界とみなす） |
| 室名が空の行が飛ばされる | 室名は「床」の左どなりの列から拾います。列の並びを確認してください |

## 検証結果

`kenshou/jwc_dump_shiage.txt` は、実際の内部仕上概要表（A3・全17室）から起こした
`jwc_temp.txt` 相当のデータです（縮尺1/100のレイヤグループで受け取った想定）。
これで次を確認しています。

- 罫線から **19行 × 10列**の格子を復元
- 見出し行から 床・巾木・壁・天井・天井高・廻り縁・備考 の列を判別、室名列を特定
- **17室すべて**を読み取り、6項目に組み替え（浴室の斜線欄は空欄、収納の天井高2段割りは1室のまま）
- 壁の欄から腰壁を分離（事務室・相談室）
- **文字が枠からはみ出さない**（枠の右端 用紙上89.50mm に対し文字の右端 最大86.90mm）
- 線色の割り当て（外枠と室名下の線が5、そのほかの罫線が2、文字が6）
- 枠どうしの**重なり 0件**、用紙からのはみ出し 0件
- 指示点が**1枚目の用紙の左上**になること

`preview_sample.pdf` / `preview_sample.png` が出来上がりです（4枚ぶん）。
これは作図データを画像に起こしたもので、Jw_cad の出力そのものではありません。

## 限界

- **実機での確認はできていません**（Jw_cad が手元にないため）。
  検証は上のダンプを使った机上のものです。
- 傾いた罫線・円弧の罫線には未対応（縦横の直線のみ）
- 罫線がブロック図形や画像になっている表は読めません
- セルの中で文字が右詰め・中央詰めになっていても、左詰めで書き出します
