# PDF / テキスト 読み上げアプリ

PDFやテキストを読み込んで、ブラウザ標準の音声合成（Web Speech API）で朗読する静的Webアプリです。
APIキーや外部サービスへの登録は不要で、追加費用もかかりません。

## 使い方

### Windows: バッチファイルで起動（かんたん）

`サーバー起動.bat` をダブルクリックすると、サーバー起動とブラウザでの表示まで自動で行われます。
Pythonが入っていない場合はその旨のメッセージが表示されるので、
[python.org](https://www.python.org/downloads/) からインストールしてください
（インストール時に「Add python.exe to PATH」に必ずチェックを入れてください）。

アプリを終了するときは、開いたウィンドウを閉じてください。

### 手動で起動する場合（Mac / Linux / Windows共通）

1. `index.html` をブラウザで直接開くか、簡易サーバーで配信します。

   ```sh
   cd pdf-tts-app
   python3 -m http.server 8000
   ```

   （Windowsのコマンドプロンプトでは `python3` ではなく `python` の場合があります）

   その後ブラウザで `http://localhost:8000` を開きます。

2. PDFファイルを選択するとテキストが自動抽出されます。テキストは直接貼り付け・編集も可能です。
3. 音声・速さ・音の高さ・音量を選んで「再生」を押すと読み上げが始まります。
   テキスト欄の途中にカーソルを置いて「ここから再生」を押すと、その位置から読み上げます。

## 読み上げエンジンの選択

| エンジン | 音質 | 準備 | 費用 |
|---|---|---|---|
| ブラウザ標準（Web Speech API） | OS内蔵音声。やや機械的 | 不要 | 無料 |
| VOICEVOX | 自然な日本語。声の種類も豊富 | VOICEVOXのインストールが必要 | 無料 |

### VOICEVOXを使う

1. [voicevox.hiroshiba.jp](https://voicevox.hiroshiba.jp/) からVOICEVOXをインストールします。
2. VOICEVOXを起動したままにします（内部で `http://localhost:50021` のエンジンが動きます）。
3. このアプリの「読み上げエンジン」で **VOICEVOX** を選ぶと、音声の一覧が読み込まれます。

VOICEVOXエンジンの既定のCORS設定（`localapps`）は `http://localhost:<任意のポート>` からの
アクセスを許可するため、追加の設定は不要です。ただし `index.html` を `file://` で直接開いた
場合は許可されないので、`サーバー起動.bat` などで `http://localhost` から開いてください。

VOICEVOXで生成した音声を配布・公開する場合は、「VOICEVOX:キャラクター名」のクレジット表記が
必要です。キャラクターごとに利用規約が異なるため、公開前に該当キャラクターの規約を確認してください。

## 仕組み

- PDFのテキスト抽出には [PDF.js](https://mozilla.github.io/pdf.js/)（`vendor/pdfjs/` にローカル同梱、CDN不要）を使用しています。
- ブラウザ標準エンジンでは各ブラウザ/OSに搭載されている `speechSynthesis`（Web Speech API）を使用します。
  利用できる声の種類（男性・女性など）はOSやブラウザによって異なります。
- VOICEVOXエンジンでは、ローカルのVOICEVOXに `/audio_query` → `/synthesis` の順でリクエストして
  WAVを取得し、`Audio` 要素で再生します。合成には時間がかかるため、再生中に次のチャンクを
  先読み合成して間が空かないようにしています。
- 長文はセンテンス単位のチャンクに分割してキューに積んで読み上げます。ブラウザによっては
  単一の長い発話が15秒前後で停止してしまう既知の不具合があるため、この分割と定期的な
  `pause`/`resume` によるキープアライブで対策しています。

## 制限事項

- ブラウザ標準エンジンの音声品質・声のバリエーションはOS/ブラウザ依存です
  （一般に日本語の音声は英語より選択肢が少なめです）。音質を重視する場合はVOICEVOXを使ってください。
- VOICEVOXはCPUでの合成に時間がかかるため、再生開始まで数秒待つことがあります。
- スキャン画像のみのPDF（OCRされていないもの）は文字が抽出できません。
- ブラウザによっては `speechSynthesis` の挙動に差異があります（特にモバイルSafari）。
