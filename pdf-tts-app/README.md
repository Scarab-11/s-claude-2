# PDF / テキスト 読み上げアプリ

PDF・テキスト・画像を読み込んで朗読する静的Webアプリです。
画像だけのPDFやスクリーンショットは文字認識（OCR）してから読み上げ、音声ファイルとして保存もできます。
APIキーや外部サービスへの登録は不要で、追加費用もかかりません。

## 使い方

### Windows: バッチファイルで起動（かんたん）

`サーバー起動.bat` をダブルクリックすると、サーバー起動とブラウザでの表示まで自動で行われます。
Microsoft Edge がインストールされていれば Edge で開きます（高音質な音声を使えるため）。
Pythonが入っていない場合はその旨のメッセージが表示されるので、
[python.org](https://www.python.org/downloads/) からインストールしてください
（インストール時に「Add python.exe to PATH」に必ずチェックを入れてください）。

**開いた黒いウィンドウは閉じないでください。** このウィンドウがサーバー本体で、
閉じるとアプリにアクセスできなくなります。アプリを終了するときに閉じてください。

### うまく開けないとき

**「このページに到達できません」と表示される**

サーバーが動いていません。ブラウザ側の問題ではないので、ブラウザを変えても直りません。

1. `サーバー起動.bat` のウィンドウが開いたままか確認する（閉じていたらもう一度実行）
2. ウィンドウに `サーバーを起動しました: http://localhost:8000` と表示され、そこで止まっている状態が正常
3. その状態のまま、ブラウザで `http://localhost:8000` を開く

ウィンドウがすぐ閉じてしまう場合は、`Address already in use` と出ていないか確認してください。
別のウィンドウでサーバーが既に動いているので、そちらのウィンドウを使えば開けます。

**更新したのに画面が変わらない**

画面の一番上にバージョン（例: `バージョン 2026-08-24`）が表示されています。
ここが古いままなら、まだ新しい版が読み込まれていません。

1. 更新が届いているか確認する

   ```sh
   cd C:\Users\Owner\s-claude-2
   git log --oneline -3
   ```

   最新のコミットが表示されていれば、ファイルは届いています
   （`Already up to date.` は「もう最新です」という意味なので、この場合は正常です）。

2. 届いているのに画面が古いときは、ブラウザが前の画面を覚えています。
   `http://localhost:8000` を開いた状態で **Ctrl+F5**（強制再読み込み）を押してください。
   それでも変わらなければ、Edgeの InPrivate ウィンドウ（Ctrl+Shift+N）で開くと確実です。

この問題自体を防ぐため、`サーバー起動.bat` は `server.py` を使って
アプリ本体のファイルをキャッシュさせない設定で配信しています。

### 手動で起動する場合（Mac / Linux / Windows共通）

1. `index.html` をブラウザで直接開くか、簡易サーバーで配信します。

   ```sh
   cd pdf-tts-app
   python3 server.py 8000
   ```

   （Windowsのコマンドプロンプトでは `python3` ではなく `python` の場合があります）

   `python3 -m http.server 8000` でも動きますが、更新後にブラウザが古い画面を
   表示し続けることがあります。`server.py` はそれを防ぐ設定で配信します。

   その後ブラウザで `http://localhost:8000` を開きます。

2. PDFファイルを選択するとテキストが自動抽出されます。テキストは直接貼り付け・編集も可能です。
   スクリーンショットなど画像だけのPDFや画像ファイルは、自動で文字認識（OCR）されます（後述）。
3. 音声・速さ・音の高さ・音量を選んで「再生」を押すと読み上げが始まります。
   テキスト欄の途中にカーソルを置いて「ここから再生」を押すと、その位置から読み上げます。

## 画像・スクリーンショットから読み上げる（OCR）

**画像だけのPDF**（スクリーンショットを貼り付けて保存したPDF、スキャンしたPDFなど）や、
**画像ファイル**（PNG / JPEG など）も読み上げられます。

こうしたファイルには「文字データ」が入っておらず、文字は絵として描かれているだけなので、
そのままでは1文字も取り出せません。そこで画像から文字を読み取る処理（OCR）を行います。

読み込み方は3通りあり、どれでも自動でOCRされます。

- 「PDF / 画像ファイルを選択」から選ぶ（複数選択できます。選んだ内容で置き換わります）
- 画面のどこかで**貼り付け（Ctrl+V）**する（Windowsの「Windows+Shift+S」で切り取った直後など）
- ファイルを画面に**ドラッグ＆ドロップ**する

貼り付けとドラッグ＆ドロップは、今あるテキストの**続きに追加**されます。
スクリーンショットを撮る→貼り付ける、を繰り返せば、複数ページ分をまとめて読み上げられます。

### 文字認識の設定

「画像の文字認識」で読み取る言語と書き方向を選べます。**縦書きの本は「日本語（縦書き）」**を
選んでください。横書き用の設定のままだと、列が混ざって意味の通らない文字列になります。

| 設定 | 用途 |
|---|---|
| 日本語（横書き） | 通常の日本語。既定値 |
| 日本語（縦書き） | 縦書きの書籍・小説 |
| 日本語＋英語 | 英単語が多く混じる文章 |
| 英語 | 英文のみ |

### 精度と時間の目安

- 1ページあたり**数秒〜十数秒**かかります。文字データのあるPDFは一瞬で読み込めるので、
  時間がかかるのは画像のページだけです。
- 画像のページが10ページを超えるPDFでは、開始前に確認のダイアログが出ます。
  処理中はいつでも「中止」でき、そこまでに読み取った分は残ります。
- はっきりした画面のスクリーンショットなら精度は高い（体感で95%以上）ですが、
  似た字形（一 と ー、二 と ニ、入 と 人 など）は間違えることがあります。
  読み上げる前にテキスト欄を直せます。
- 小さい文字・傾いた写真・背景の濃い画像は苦手です。**拡大して撮り直す**と改善します。
- 折り返しで途中改行された行はつなぎ直してから読み上げます。句点で終わる行は分けたままなので、
  箇条書きや詩の形は保たれます。

初回だけ読み取り用データ（約2MB）の読み込みで十数秒かかります。2回目以降は
ブラウザに保存されるため、すぐ始まります。すべてローカルにあるので、
ネット接続もアカウント登録も不要で、画像が外部に送信されることもありません。

## 読み上げエンジンの選択

| エンジン | 音質 | 準備 | 費用 |
|---|---|---|---|
| ブラウザ標準（Web Speech API） | OS内蔵音声。やや機械的 | 不要 | 無料 |
| ブラウザ標準 + Microsoft Edge | Edgeのニューラル音声。かなり自然 | Edgeで開くだけ（要ネット接続） | 無料 |
| VOICEVOX | 自然な日本語。声の種類も豊富 | VOICEVOXのインストールが必要 | 無料 |

### Microsoft Edge の高音質音声を使う

Edgeは「Microsoft Nanami Online (Natural)」のようなクラウド上のニューラル音声を持っており、
これは Web Speech API 経由でも利用できます。**アプリ側の設定は不要**で、Edgeで
`http://localhost:8000` を開くだけです。

音声の一覧では、高音質な音声（名前に `Natural` / `Neural` を含むもの、およびリモート音声）に
**【高音質】** を付けて先頭に並べているので、そのまま選べば使えます。見つからない場合は
その旨がヒントに表示されます。

クラウド音声のためネット接続が必要です。また、Edgeのバージョンによっては `getVoices()` が
Natural音声を `Microsoft undefined Online (Natural) - undefined` として返す不具合が報告されています。
その場合はEdgeを最新版に更新してから開き直してください。

### VOICEVOXを使う

1. [voicevox.hiroshiba.jp](https://voicevox.hiroshiba.jp/) からVOICEVOXをインストールします。
2. VOICEVOXを起動したままにします（内部で `http://localhost:50021` のエンジンが動きます）。
3. このアプリの「読み上げエンジン」で **VOICEVOX** を選ぶと、音声の一覧が読み込まれます。

VOICEVOXエンジンの既定のCORS設定（`localapps`）は `http://localhost:<任意のポート>` からの
アクセスを許可するため、追加の設定は不要です。ただし `index.html` を `file://` で直接開いた
場合は許可されないので、`サーバー起動.bat` などで `http://localhost` から開いてください。

VOICEVOXで生成した音声を配布・公開する場合は、「VOICEVOX:キャラクター名」のクレジット表記が
必要です。キャラクターごとに利用規約が異なるため、公開前に該当キャラクターの規約を確認してください。

## 音声ファイル（MP3 / WAV）として保存する

**VOICEVOXを選んでいるときだけ**使えます。「4. 音声ファイルとして保存」で形式を選び、
「音声ファイルを作成」を押すとブラウザのダウンロードとして保存されます。

ブラウザ標準エンジン（Edgeのニューラル音声を含む）では保存できません。Web Speech API は
音声を出力デバイスへ直接再生するだけで、音声データを取得する手段が仕様上存在しないためです。

| 形式 | 目安のサイズ | 用途 |
|---|---|---|
| MP3（64kbps モノラル） | 約 0.5 MB / 分（1時間で約30MB） | スマホに入れて聴く |
| WAV（24kHz 16bit モノラル） | 約 2.9 MB / 分（1時間で約170MB） | 編集する・音質を落としたくない |

読み上げと同じく、速さ・音の高さの設定が反映されます。長い文章では合成に時間がかかるため、
進捗が表示され、「中止」でいつでも止められます。

### 保存先の指定

Chrome / Edge では、「音声ファイルを作成」を押すと**最初に保存先を選ぶダイアログ**が開きます
（Windows標準の「名前を付けて保存」）。フォルダもファイル名も自由に指定できます。

保存先を先に聞くのは、`showSaveFilePicker` がクリック直後の一時的なユーザー操作中にしか
呼び出せないためです。本一冊分の合成には数分かかることがあり、合成後に呼ぶと期限切れで失敗します。
先に保存先を確保することで、合成した音声を**ファイルへ逐次書き込める**という利点もあり、
長い本でもデータ全体をメモリに載せずに済みます（WAVはヘッダを仮置きし、
書き込み終了後にサイズを埋め直しています）。

このAPIに対応していないブラウザ（Firefox / Safari）では、従来どおりダウンロードフォルダに
保存されます。既定のファイル名は `yomiage_日付-時刻.mp3` 形式です。ブラウザは非ASCII文字を含む
ダウンロード名を破棄して拡張子のない `download` として保存してしまうため、意図的にASCIIにしています。

ダウンロードになる場合でも、ブラウザ側の設定
（Edge: 設定 → ダウンロード → **「ダウンロード時の保存場所を指定する」**）をONにすれば、
毎回保存先を選べます。

## 仕組み

- PDFのテキスト抽出には [PDF.js](https://mozilla.github.io/pdf.js/)（`vendor/pdfjs/` にローカル同梱、CDN不要）を使用しています。
- 文字データが8文字未満のページは画像のページとみなし、そのページだけを横幅2000px程度に
  拡大して描画してから [tesseract.js](https://tesseract.projectnaptha.com/)
  （`vendor/tesseract/` に同梱、学習データも含めてローカル）で文字認識します。
  日本語のOCR結果は文字ごとに空白が入るため、日本語の前後の空白だけを取り除いています。
- ブラウザ標準エンジンでは各ブラウザ/OSに搭載されている `speechSynthesis`（Web Speech API）を使用します。
  利用できる声の種類（男性・女性など）はOSやブラウザによって異なります。音声一覧は日本語を優先し、
  さらに高音質な音声（`Natural` / `Neural` を含む名前、または `localService === false` のリモート音声）を
  先頭に並べ替えて表示します。
- VOICEVOXエンジンでは、ローカルのVOICEVOXに `/audio_query` → `/synthesis` の順でリクエストして
  WAVを取得し、`Audio` 要素で再生します。合成には時間がかかるため、再生中に次のチャンクを
  先読み合成して間が空かないようにしています。
- 音声ファイルの保存では、各チャンクのWAVを解析してPCMを取り出し、連結して出力します。
  MP3は [lamejs](https://github.com/zhuker/lamejs)（LGPL-3.0、`vendor/lamejs/` に同梱）で
  エンコードします。メモリを抑えるため、チャンクごとに逐次エンコードして
  MP3データのみを保持します。
- 長文はセンテンス単位のチャンクに分割してキューに積んで読み上げます。ブラウザによっては
  単一の長い発話が15秒前後で停止してしまう既知の不具合があるため、この分割と定期的な
  `pause`/`resume` によるキープアライブで対策しています。

## 制限事項

- ブラウザ標準エンジンの音声品質・声のバリエーションはOS/ブラウザ依存です
  （一般に日本語の音声は英語より選択肢が少なめです）。音質を重視する場合はVOICEVOXを使ってください。
- VOICEVOXはCPUでの合成に時間がかかるため、再生開始まで数秒待つことがあります。
- 画像・スキャンPDFのOCRは100%正確ではありません。読み間違いは読み上げ前にテキスト欄で直せます。
- 表・段組み・図の中の文字は、読む順番が入れ替わることがあります。
- ブラウザによっては `speechSynthesis` の挙動に差異があります（特にモバイルSafari）。
